# 5장. 차트 분석 전략 기초

> 지표 외에 차트 그 자체를 분석하는 방법을 배웁니다.
> 지지/저항, 추세선, 차트 패턴은 기술적 분석의 뼈대가 되는 개념입니다.

---

## 5.1 지지선과 저항선

### 지지선(Support)이란?

**지지선**은 가격이 하락하다가 **더 이상 내려가지 못하고 반등하는 가격대**입니다.

**비유**: 공을 바닥에 떨어뜨리면 바닥에서 튀어 오릅니다. 이 "바닥"이 지지선입니다.

```
  가격
   │
   │   ╲        ╱╲       ╱
   │    ╲      ╱  ╲     ╱
   │     ╲    ╱    ╲   ╱
   │      ╲  ╱      ╲ ╱
   │───────╲╱────────╲───  ← 지지선 (가격이 반복해서 반등)
   │
   └────────────────────→ 시간
```

### 저항선(Resistance)이란?

**저항선**은 가격이 상승하다가 **더 이상 올라가지 못하고 하락하는 가격대**입니다.

**비유**: 천장이 있는 방에서 공을 위로 던지면 천장에 부딪혀 떨어집니다. 이 "천장"이 저항선입니다.

```
  가격
   │
   │───────╲────────╲────  ← 저항선 (가격이 반복해서 막힘)
   │      ╱ ╲      ╱ ╲
   │     ╱   ╲    ╱   ╲
   │    ╱     ╲  ╱     ╲
   │   ╱       ╲╱       ╲
   │
   └────────────────────→ 시간
```

### 지지선/저항선 그리는 법

1. 과거 차트에서 가격이 **여러 번 반등하거나 막힌 지점**을 찾습니다
2. 해당 지점들을 **수평선**으로 연결합니다
3. 최소 **2회 이상** 반응한 지점이 신뢰도 높은 지지/저항선입니다

**실전 팁**:
- **고점과 저점**에 선을 그어봅니다
- **정확한 가격이 아닌 가격대(Zone)**로 보는 것이 더 현실적입니다
- **거래량이 많이 발생한 가격대**는 강한 지지/저항이 됩니다

### 지지선과 저항선의 역할 전환

**중요한 원칙**: 지지선이 돌파되면 저항선이 되고, 저항선이 돌파되면 지지선이 됩니다.

```
  가격
   │                    ╱───  ← 돌파 후 저항선이 지지선으로
   │                   ╱
   │──────╲───────────●────── ← 이전 저항선
   │     ╱ ╲         ╱
   │    ╱   ╲       ╱
   │   ╱     ╲─────╱
   │
   └────────────────────→ 시간
```

### 심리적 지지/저항선

**라운드 넘버(Round Number)**는 심리적 지지/저항이 됩니다.
- 예: 10,000원, 50,000원, 100,000원 등
- 예: 비트코인 $50,000, $60,000, $100,000 등

사람들이 이런 숫자 근처에서 매매 결정을 내리기 때문에 자연스럽게 지지/저항이 형성됩니다.

> 💡 **실전 활용 팁**
> 1. **지지선 근처에서 매수, 저항선 근처에서 매도**가 기본 전략
> 2. 지지선이 확실히 돌파되면 **손절매** 실행
> 3. 저항선 돌파 시 **추가 매수**(추세 추종) 고려

## 5.2 추세선 그리는 법과 해석

### 추세선(Trend Line)이란?

**추세선**은 가격의 방향성을 보여주는 선입니다.

### 추세의 3가지 종류

**1. 상승 추세(Uptrend)**
- 저점이 계속 높아지는 상태 (**Higher Lows**)
- 저점들을 연결하여 추세선 그리기

```
  가격
   │              ╱
   │          ╱──╱
   │      ╱──╱
   │   ╱──╱      ← 저점을 연결한 상승 추세선
   │ ╱
   └────────────→ 시간
```

**2. 하락 추세(Downtrend)**
- 고점이 계속 낮아지는 상태 (**Lower Highs**)
- 고점들을 연결하여 추세선 그리기

```
  가격
   │ ╲
   │  ╲──╲      ← 고점을 연결한 하락 추세선
   │      ╲──╲
   │          ╲──╲
   │              ╲
   └────────────→ 시간
```

**3. 횡보 추세(Sideways / Range)**
- 고점과 저점이 비슷한 수준에서 움직임
- 수평 지지/저항선 안에서 진동

### 추세선 그리는 법 (상승 추세)

1. 최소 **2개의 저점**을 찾습니다
2. 두 저점을 직선으로 연결합니다
3. **3번째 저점**이 이 선 근처에서 반등하면 추세선 **확정**
4. 추세선이 3회 이상 테스트되면 **신뢰도 높음**

### 추세선의 활용

- **가격이 추세선을 유지**: 추세 지속 → 추세 방향으로 매매
- **가격이 추세선 돌파**: 추세 전환 가능성 → 반대 방향 매매 고려
- **추세선 기울기가 급할수록**: 단기적이고 불안정함
- **추세선 기울기가 완만할수록**: 장기적이고 안정적

> ⚠️ **주의**
> 추세선은 주관적일 수 있습니다. 동일한 차트를 보고도 사람마다 다르게 그릴 수 있습니다.
> 따라서 **거래량, 지표 등 다른 요소**와 함께 확인하는 것이 중요합니다.

## 5.3 채널 분석

### 채널(Channel)이란?

**채널**은 **평행한 두 추세선** 사이의 구간에서 가격이 움직이는 패턴입니다.

### 채널의 종류

**1. 상승 채널**
```
  가격
   │          ╱ (상단선)
   │       ╱──╱
   │    ╱──╱  ╱── (상단선: 고점 연결)
   │  ╱──╱ ╱──
   │╱  ╱──╱
   │  ╱── (하단선: 저점 연결, 추세선)
   └────────────→ 시간
```

**2. 하락 채널**
```
  가격
   │╲
   │ ╲──╲ (상단선)
   │──╲  ╲──╲
   │  ──╲  ╲  ╲──
   │     ──╲  ╲
   │        ──╲──── (하단선)
   └────────────→ 시간
```

**3. 수평 채널 (박스권)**
```
  가격
   │
   │─────────────────── (상단: 저항선)
   │  ╱╲    ╱╲    ╱╲
   │ ╱  ╲  ╱  ╲  ╱  ╲
   │╱    ╲╱    ╲╱    ╲
   │─────────────────── (하단: 지지선)
   │
   └────────────→ 시간
```

### 채널 매매 전략

**기본 전략**:
- **채널 하단에서 매수**
- **채널 상단에서 매도**
- **채널 이탈 시 손절 또는 추세 추종**

> 💡 **실전 활용 팁**
> 1. 채널 폭이 **넓을수록** 수익 기회가 큼
> 2. 채널 이탈(Breakout)은 강한 신호 → 큰 움직임 가능
> 3. 수평 채널(박스권)은 **RSI + 볼린저 밴드**와 궁합이 좋음

## 5.4 주요 차트 패턴

### 패턴 1: 헤드앤숄더 (Head and Shoulders)

**형태**: 3개의 봉우리가 가운데가 가장 높은 모양 (사람의 머리와 어깨와 비슷)

```
  가격
   │       Head
   │        ╱╲
   │       ╱  ╲
   │  L.S ╱    ╲ R.S
   │   ╱╲╱      ╲╱╲
   │  ╱          ╲
   │─────────────── ← 넥라인(Neckline)
   │
   └────────────→ 시간

   L.S = Left Shoulder (왼쪽 어깨)
   Head = 머리 (가장 높은 봉우리)
   R.S = Right Shoulder (오른쪽 어깨)
```

- **의미**: **상승 추세에서 하락 전환**의 강력한 신호
- **매매 타이밍**: 넥라인 하향 돌파 시 **매도**
- **목표 가격**: 넥라인 - (머리 고점 - 넥라인) 만큼 하락 예상
- **실전 팁**: 오른쪽 어깨 완성 후 넥라인 돌파를 확인하고 진입

### 패턴 2: 역 헤드앤숄더 (Inverse Head and Shoulders)

**형태**: 헤드앤숄더를 뒤집은 형태 (3개의 골짜기)

```
   │─────────────── ← 넥라인
   │  ╲          ╱
   │   ╲╱╲      ╱╲╱
   │     ╲    ╱
   │      ╲  ╱
   │       ╲╱
   │       Head (가장 낮음)
```

- **의미**: **하락 추세에서 상승 전환**의 강력한 신호
- **매매 타이밍**: 넥라인 상향 돌파 시 **매수**

### 패턴 3: 이중천장 (Double Top)

**형태**: 두 개의 비슷한 높이의 봉우리

```
  가격
   │
   │     ╱╲     ╱╲
   │    ╱  ╲   ╱  ╲
   │   ╱    ╲ ╱    ╲
   │──╱──────╳──────╲── ← 지지선
   │                  ╲
   │                   ╲
   └────────────→ 시간
```

- **의미**: 상승 추세 끝 → **하락 전환**
- **매매 타이밍**: 두 봉우리 사이의 저점(지지선)을 하향 돌파 시 **매도**
- **실전 팁**: 거래량이 두 번째 봉우리에서 감소하면 신뢰도 상승

### 패턴 4: 이중바닥 (Double Bottom)

**형태**: 두 개의 비슷한 깊이의 골짜기

```
  가격
   │──╲──────────╲── ← 넥라인(저항선)
   │   ╲   ╱╲    ╱
   │    ╲ ╱  ╲  ╱
   │     ╲    ╲╱
   │      ╲   ╱
   │       ╲ ╱
   │        V
   └────────────→ 시간
```

- **의미**: 하락 추세 끝 → **상승 전환**
- **매매 타이밍**: 두 골짜기 사이의 고점(넥라인)을 상향 돌파 시 **매수**
- **실전 팁**: 두 번째 바닥에서 거래량이 증가하면 신뢰도 상승

### 패턴 5: 삼각수렴 (Triangle)

**3가지 종류**:

**① 대칭삼각형 (Symmetrical Triangle)**
```
  가격
   │╲       ╱╲
   │ ╲     ╱  ╲
   │  ╲───╱────╲───  ← 상단선 (하락)
   │   ╲ ╱
   │    X
   │   ╱ ╲
   │  ╱   ╲───╱───  ← 하단선 (상승)
   │ ╱     ╲ ╱
   │╱       V
   └────────────→ 시간
```
- **의미**: 매수/매도 세력 균형 → 방향 불확실
- **매매**: 돌파 방향 확인 후 진입

**② 상승삼각형 (Ascending Triangle)**
```
  가격
   │────────────  ← 수평 저항선
   │  ╱╲  ╱╲  ╱
   │ ╱  ╲╱  ╲╱
   │╱
   │╱  ← 상승 지지선
   └────────────→ 시간
```
- **의미**: 강한 매수세 → **상승 돌파 가능성 높음**
- **매매**: 저항선 상향 돌파 시 **매수**

**③ 하락삼각형 (Descending Triangle)**
```
  가격
   │╲
   │ ╲  ← 하락 저항선
   │  ╲╲  ╱╲  ╱
   │   ╲╱  ╲╱
   │────────────  ← 수평 지지선
   └────────────→ 시간
```
- **의미**: 강한 매도세 → **하락 돌파 가능성 높음**
- **매매**: 지지선 하향 돌파 시 **매도**

### 패턴 6: 깃발형 (Flag)

**형태**: 급격한 상승(또는 하락) 후 짧은 조정 구간

```
  가격
   │           ╱
   │          ╱──── (이후 추가 상승)
   │         ╱
   │    ╱───╱
   │   ╱ 깃발대
   │  ╱ (급상승)
   │ ╱
   └────────────→ 시간
```

- **의미**: 추세 지속 중 **잠깐의 휴식**
- **매매**: 깃발 구간 돌파 시 기존 방향으로 진입

### 패턴 7: 컵앤핸들 (Cup and Handle)

**형태**: U자 모양의 컵 + 작은 하락 손잡이

```
  가격
   │              ╱
   │   ╲         ╱
   │    ╲       ╱  손잡이
   │     ╲    ╱╲╱╲
   │      ╲  ╱    ╲╱╲
   │       ╲╱
   │     (컵)
   └────────────→ 시간
```

- **의미**: 장기 **상승 전환** 신호 (윌리엄 오닐이 유명하게 만든 패턴)
- **매매**: 손잡이 돌파 시 **매수**

## 5.5 TradingView 그리기 도구 사용법

TradingView는 차트 위에 직접 선, 도형, 텍스트를 그릴 수 있는 강력한 도구를 제공합니다.

### 그리기 도구바 위치

왼쪽 사이드바에서 접근 가능합니다.

### 자주 쓰는 그리기 도구

| 도구 | 용도 | 단축키 |
|------|------|--------|
| **수평선(Horizontal Line)** | 지지선/저항선 표시 | Alt+H |
| **추세선(Trend Line)** | 상승/하락 추세선 | Alt+T |
| **수직선(Vertical Line)** | 특정 시점 표시 | Alt+V |
| **사각형(Rectangle)** | 박스권, 지지/저항 영역 | - |
| **피보나치 되돌림** | 되돌림 비율 표시 | Alt+F |
| **텍스트(Text)** | 메모 작성 | - |
| **경로(Path)** | 자유 곡선 | - |

### 사용 방법

1. **왼쪽 도구바**에서 원하는 도구 클릭
2. 차트 위에서 **클릭 & 드래그**로 그리기
3. 그린 도형을 **더블 클릭**하면 색상, 두께 등 설정 가능
4. **휴지통 아이콘**으로 삭제

### 피보나치 되돌림 활용

**피보나치 비율**: 0%, 23.6%, 38.2%, 50%, 61.8%, 78.6%, 100%

**사용법**:
1. 그리기 도구에서 **피보나치 되돌림** 선택
2. **최저점에서 최고점**까지 드래그 (상승 추세일 때)
3. 중요한 되돌림 비율: **38.2%, 50%, 61.8%**
4. 이 구간이 **매수 기회**가 될 수 있음

> 💡 **실전 활용 팁**
> 1. 주요 지지/저항선을 **수평선**으로 표시하여 한눈에 보기
> 2. 추세선을 그려 **추세 이탈**을 감지
> 3. 매수/매도 가격을 **텍스트 메모**로 기록하여 투자 일지 작성

## 5.6 5장 요약

- **지지선**과 **저항선**은 매매의 기준점이 되는 가장 중요한 개념입니다.
- 돌파된 저항선은 지지선이 되고, 돌파된 지지선은 저항선이 됩니다.
- **추세선**은 가격의 방향성을 보여주며, 상승/하락/횡보 추세를 파악할 수 있습니다.
- **채널**은 평행한 두 추세선 사이에서 가격이 움직이는 패턴입니다.
- **주요 차트 패턴**: 헤드앤숄더, 이중천장/바닥, 삼각수렴, 깃발형, 컵앤핸들
- TradingView의 그리기 도구로 **직접 분석**하며 감각을 키우세요.

> ⚠️ **차트 패턴의 한계**
> 모든 패턴이 교과서처럼 완벽하게 나타나지 않습니다.
> 패턴은 **확률**일 뿐, 100% 정답이 아닙니다.
> 반드시 **거래량, 지표, 뉴스** 등과 함께 종합적으로 판단하세요.
