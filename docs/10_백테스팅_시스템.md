# 10장. 백테스팅 시스템 구축

> **백테스팅(Backtesting)**은 전략이 과거에 어떤 성과를 냈을지를 시뮬레이션하는 과정입니다.
> 실전에 투입하기 전에 반드시 거쳐야 하는 가장 중요한 단계입니다.

---

## 10.1 백테스팅이란 무엇인가

### 정의

**백테스팅**은 **과거 가격 데이터**에 현재의 매매 전략을 적용하여, **가상의 매매를 실행**하고 성과를 측정하는 방법입니다.

**비유**:
> 새 요리 레시피를 만들 때, 손님에게 바로 팔기 전에 먼저 직접 만들어 맛을 보는 것과 같습니다.
> 백테스팅은 "내가 이 전략으로 과거에 투자했다면 얼마를 벌었을까?"를 확인하는 과정입니다.

### 백테스팅의 목적

1. **수익성 검증**: 전략이 실제로 수익을 내는지 확인
2. **리스크 측정**: 최대 손실(MDD), 변동성 등 파악
3. **파라미터 최적화**: RSI 기간 14 vs 21 중 어느 것이 더 나은지 비교
4. **전략 비교**: 여러 전략 중 어떤 것을 선택할지 판단

### 백테스팅의 한계

> ⚠️ **절대 기억할 것: 과거 성과가 미래를 보장하지 않는다**

백테스팅에는 다음과 같은 함정이 있습니다:

1. **과최적화(Overfitting)**: 과거 데이터에 맞춰 너무 세밀하게 조정 → 미래에는 작동 안 함
2. **Look-ahead Bias**: 미래 데이터를 실수로 사용 → 비현실적으로 높은 수익
3. **거래 비용 무시**: 수수료, 슬리피지를 반영 안 하면 실제보다 수익 과대 평가
4. **생존자 편향**: 지금 상장된 종목만 분석 → 상폐된 종목의 영향 누락

## 10.2 주요 성과 지표

백테스팅 결과를 평가하는 핵심 지표들입니다.

### 10.2.1 총수익률 (Total Return)

```
총수익률 = (최종 자산 - 초기 자산) ÷ 초기 자산 × 100
```

**예시**: 1,000만원 → 1,500만원
- 총수익률 = (1,500 - 1,000) ÷ 1,000 × 100 = **+50%**

### 10.2.2 연환산 수익률 (CAGR)

**CAGR(Compound Annual Growth Rate)**: 연평균 복리 수익률

```
CAGR = (최종 자산 / 초기 자산)^(1/년수) - 1
```

**예시**: 3년 동안 1,000만원 → 1,500만원
- CAGR = (1,500 / 1,000)^(1/3) - 1 = 0.1447 = **약 14.47%/년**

### 10.2.3 최대낙폭 (MDD, Maximum Drawdown)

**MDD**: 백테스팅 기간 중 **고점 대비 최대 손실폭**

```
낙폭(Drawdown) = (고점 - 현재) ÷ 고점
MDD = max(Drawdown)
```

**예시**:
- 자산: 1,000 → 1,200 → 900 → 1,100 → 1,300
- 고점 1,200 → 저점 900 : 낙폭 25%
- **MDD = -25%**

> 💡 **MDD의 중요성**
> MDD가 크면 실전에서 심리적 압박으로 전략을 포기할 가능성이 높습니다.
> 일반적으로 MDD는 **-20% 이내**를 목표로 합니다.

### 10.2.4 승률 (Win Rate)

```
승률 = 수익 거래 수 ÷ 전체 거래 수 × 100
```

**예시**: 100번 매매, 60번 수익, 40번 손실
- 승률 = 60 ÷ 100 × 100 = **60%**

### 10.2.5 손익비 (Profit Factor)

```
손익비 = 총 수익 ÷ 총 손실
```

- **손익비 > 1**: 수익 전략
- **손익비 > 1.5**: 우수한 전략
- **손익비 > 2**: 매우 우수한 전략

### 10.2.6 샤프 지수 (Sharpe Ratio)

**샤프 지수**: 변동성 대비 수익률, 즉 **리스크 대비 효율성**을 측정

```
샤프 지수 = (연평균 수익률 - 무위험 수익률) ÷ 수익률의 표준편차
```

- **샤프 지수 < 1**: 부족한 전략
- **샤프 지수 1~2**: 양호한 전략
- **샤프 지수 2~3**: 우수한 전략
- **샤프 지수 > 3**: 매우 우수한 전략 (드뭄)

> 💡 **승률 vs 손익비**
> 승률이 낮아도 손익비가 크면 수익 전략입니다. (예: 승률 30%지만 손익비 3 → 수익)
> 반대로 승률이 높아도 손익비가 작으면 손실 전략일 수 있습니다.

```pinescript

strategy("Golden Cross Strategy", overlay=true,
         initial_capital=10000000,  // 초기 자본 1,000만원
         default_qty_type=strategy.percent_of_equity,
         default_qty_value=100,      // 자산의 100% 사용
         commission_type=strategy.commission.percent,
         commission_value=0.05)      // 수수료 0.05%

// 파라미터

longLen = input.int(20, "Long MA")

// 지표 계산
sma5 = ta.sma(close, shortLen)
sma20 = ta.sma(close, longLen)

// 교차 감지
goldenCross = ta.crossover(sma5, sma20)
deadCross = ta.crossunder(sma5, sma20)

// 플로팅
plot(sma5, color=color.yellow, title="SMA 5")
plot(sma20, color=color.blue, title="SMA 20")

// 매매 실행
if goldenCross
    strategy.entry("Long", strategy.long)
if deadCross
    strategy.close("Long")
```

### 10.4.1 데이터 수집

**암호화폐 (업비트)**:

```python
"""
업비트 과거 캔들 데이터 수집
"""
from __future__ import annotations

from datetime import datetime, timedelta

import pandas as pd
import pyupbit


def fetch_upbit_history(
    ticker: str = "KRW-BTC",
    interval: str = "day",
    count: int = 1000,
) -> pd.DataFrame:
    """
    업비트에서 과거 캔들 데이터 조회

    Args:
        ticker: 종목 심볼
        interval: "day", "minute60", "minute240", "week" 등
        count: 가져올 캔들 개수 (업비트는 한 번에 최대 200)

    Returns:
        OHLCV DataFrame (index는 datetime)
    """
    if count <= 200:
        return pyupbit.get_ohlcv(ticker, interval=interval, count=count)

    # 200개 초과 시 반복 호출
    all_df: list[pd.DataFrame] = []
    to_date: datetime | None = None
    remaining = count

    while remaining > 0:
        fetch_count = min(remaining, 200)
        df = pyupbit.get_ohlcv(
            ticker,
            interval=interval,
            count=fetch_count,
            to=to_date,
        )
        if df is None or len(df) == 0:
            break
        all_df.append(df)
        remaining -= len(df)
        to_date = df.index[0] - timedelta(seconds=1)

    return pd.concat(all_df[::-1]).drop_duplicates().sort_index()
```

```python
"""

from __future__ import annotations

import pandas as pd
from pykrx import stock


def fetch_krx_history(
    stock_code: str = "005930",
    start: str = "20200101",
    end: str = "20241231",
) -> pd.DataFrame:
    """
    KRX에서 종목의 과거 일봉 데이터 조회

    Args:
        stock_code: 종목 코드 (예: "005930")
        start: 시작일 (YYYYMMDD)
        end: 종료일 (YYYYMMDD)

    Returns:
        OHLCV DataFrame
    """
    df = stock.get_market_ohlcv(start, end, stock_code)
    df.columns = ["open", "high", "low", "close", "volume", "value"]
    return df[["open", "high", "low", "close", "volume"]]
```

### 10.4.2 백테스팅 엔진 구현

```python
"""
간단한 백테스팅 엔진
"""
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Callable

import numpy as np
import pandas as pd


@dataclass
class Trade:
    """단일 거래 기록"""

    entry_time: pd.Timestamp
    exit_time: pd.Timestamp | None
    entry_price: float
    exit_price: float | None
    quantity: float
    side: str  # "LONG"
    pnl: float = 0.0
    pnl_pct: float = 0.0


@dataclass
class BacktestResult:
    """백테스팅 결과"""

    initial_capital: float
    final_capital: float
    equity_curve: pd.Series
    trades: list[Trade] = field(default_factory=list)

    @property
    def total_return_pct(self) -> float:
        return (self.final_capital - self.initial_capital) / self.initial_capital * 100

    @property
    def total_trades(self) -> int:
        return len(self.trades)

    @property
    def win_rate(self) -> float:
        if not self.trades:
            return 0.0
        wins = sum(1 for t in self.trades if t.pnl > 0)
        return wins / len(self.trades) * 100

    @property
    def profit_factor(self) -> float:
        total_profit = sum(t.pnl for t in self.trades if t.pnl > 0)
        total_loss = abs(sum(t.pnl for t in self.trades if t.pnl < 0))
        if total_loss == 0:
            return float("inf") if total_profit > 0 else 0.0
        return total_profit / total_loss

    @property
    def max_drawdown_pct(self) -> float:
        """최대낙폭(MDD) 계산"""
        rolling_max = self.equity_curve.cummax()
        drawdown = (self.equity_curve - rolling_max) / rolling_max
        return float(drawdown.min() * 100)

    @property
    def sharpe_ratio(self) -> float:
        """일간 수익률 기준 샤프 지수 (연환산)"""
        returns = self.equity_curve.pct_change().dropna()
        if returns.std() == 0:
            return 0.0
        # 일간 기준 → 연환산 (거래일 252일 가정)
        return float(returns.mean() / returns.std() * np.sqrt(252))

    def summary(self) -> dict[str, float]:
        """요약 지표"""
        return {
            "total_return_pct": round(self.total_return_pct, 2),
            "total_trades": self.total_trades,
            "win_rate": round(self.win_rate, 2),
            "profit_factor": round(self.profit_factor, 2),
            "max_drawdown_pct": round(self.max_drawdown_pct, 2),
            "sharpe_ratio": round(self.sharpe_ratio, 2),
            "initial_capital": self.initial_capital,
            "final_capital": round(self.final_capital, 0),
        }


def run_backtest(
    df: pd.DataFrame,
    signal_fn: Callable[[pd.DataFrame], pd.DataFrame],
    initial_capital: float = 10_000_000,
    commission_pct: float = 0.0005,  # 0.05%
    slippage_pct: float = 0.0002,    # 0.02%
) -> BacktestResult:
    """
    백테스팅 실행

    Args:
        df: OHLCV DataFrame
        signal_fn: signal 컬럼("BUY"/"SELL"/"HOLD")을 추가하는 함수
        initial_capital: 초기 자본
        commission_pct: 거래 수수료
        slippage_pct: 슬리피지

    Returns:
        BacktestResult
    """
    df = signal_fn(df.copy())

    cash = initial_capital
    position_qty = 0.0
    equity_history: list[float] = []
    trades: list[Trade] = []
    current_trade: Trade | None = None

    for timestamp, row in df.iterrows():
        close = float(row["close"])
        signal = row.get("signal", "HOLD")

        # 매수
        if signal == "BUY" and position_qty == 0 and cash > 0:
            entry_price = close * (1 + slippage_pct)
            qty = cash / entry_price
            fee = qty * entry_price * commission_pct
            cash -= qty * entry_price + fee
            position_qty = qty
            current_trade = Trade(
                entry_time=timestamp,  # type: ignore
                exit_time=None,
                entry_price=entry_price,
                exit_price=None,
                quantity=qty,
                side="LONG",
            )

        # 매도
        elif signal == "SELL" and position_qty > 0 and current_trade:
            exit_price = close * (1 - slippage_pct)
            proceeds = position_qty * exit_price
            fee = proceeds * commission_pct
            cash += proceeds - fee

            current_trade.exit_time = timestamp  # type: ignore
            current_trade.exit_price = exit_price
            current_trade.pnl = (
                position_qty * (exit_price - current_trade.entry_price) - fee
            )
            current_trade.pnl_pct = (
                (exit_price - current_trade.entry_price) / current_trade.entry_price * 100
            )
            trades.append(current_trade)

            current_trade = None
            position_qty = 0.0

        # 현재 자산 평가
        equity = cash + position_qty * close
        equity_history.append(equity)

    # 남은 포지션 강제 청산
    if position_qty > 0 and current_trade:
        last_close = float(df["close"].iloc[-1])
        cash += position_qty * last_close * (1 - commission_pct)
        current_trade.exit_time = df.index[-1]  # type: ignore
        current_trade.exit_price = last_close
        current_trade.pnl = position_qty * (last_close - current_trade.entry_price)
        current_trade.pnl_pct = (
            (last_close - current_trade.entry_price) / current_trade.entry_price * 100
        )
        trades.append(current_trade)

    equity_curve = pd.Series(equity_history, index=df.index)

    return BacktestResult(
        initial_capital=initial_capital,
        final_capital=float(equity_curve.iloc[-1]),
        equity_curve=equity_curve,
        trades=trades,
    )
```

### 10.4.3 실제 사용 예제 (골든크로스)

```python
"""
골든크로스 전략 백테스팅 실행 예제
"""
from __future__ import annotations

import pandas as pd
import pyupbit

# 6장에서 만든 전략 함수 재사용
from strategies import golden_cross_strategy
from backtest_engine import run_backtest


def main() -> None:
    # 1. 데이터 가져오기
    df = pyupbit.get_ohlcv("KRW-BTC", interval="day", count=500)
    print(f"데이터 기간: {df.index[0]} ~ {df.index[-1]} ({len(df)}일)")

    # 2. 백테스트 실행
    result = run_backtest(
        df,
        signal_fn=lambda d: golden_cross_strategy(d, short_period=5, long_period=20),
        initial_capital=10_000_000,
        commission_pct=0.0005,
        slippage_pct=0.0002,
    )

    # 3. 결과 출력
    summary = result.summary()
    print("\n=== 백테스팅 결과 ===")
    for key, value in summary.items():
        print(f"{key:20s}: {value}")


if __name__ == "__main__":
    main()
```

```python
"""
백테스팅 결과 시각화 (matplotlib)
"""
from __future__ import annotations

import matplotlib.pyplot as plt
import pandas as pd

from backtest_engine import BacktestResult


def plot_backtest_result(result: BacktestResult, title: str = "Backtest") -> None:
    """
    자산 곡선과 낙폭을 시각화
    """
    fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8), sharex=True)

    # 자산 곡선
    ax1.plot(result.equity_curve.index, result.equity_curve.values, label="Equity")
    ax1.axhline(result.initial_capital, color="gray", linestyle="--", label="Initial")
    ax1.set_title(f"{title} - Equity Curve")
    ax1.set_ylabel("Capital (KRW)")
    ax1.legend()
    ax1.grid(True, alpha=0.3)

    # 매매 포인트 표시
    for trade in result.trades:
        if trade.exit_time and trade.exit_price:
            color = "green" if trade.pnl > 0 else "red"
            ax1.axvspan(
                trade.entry_time,
                trade.exit_time,
                alpha=0.1,
                color=color,
            )

    # 낙폭
    rolling_max = result.equity_curve.cummax()
    drawdown = (result.equity_curve - rolling_max) / rolling_max * 100
    ax2.fill_between(drawdown.index, drawdown.values, 0, color="red", alpha=0.3)
    ax2.plot(drawdown.index, drawdown.values, color="red")
    ax2.set_title("Drawdown (%)")
    ax2.set_ylabel("%")
    ax2.set_xlabel("Date")
    ax2.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.savefig("backtest_result.png", dpi=100)
    plt.show()
```

## 10.5 백테스트 결과를 FastAPI 엔드포인트로 제공

9장의 FastAPI 서버에 백테스팅 API를 추가할 수 있습니다.

### `app/routers/backtest.py`

```python
"""
백테스팅 API 라우터
"""
from __future__ import annotations

from typing import Literal

from fastapi import APIRouter, Query
from pydantic import BaseModel

import pyupbit

from strategies import (
    golden_cross_strategy,
    rsi_bollinger_strategy,
    macd_volume_strategy,
    breakout_strategy,
    trend_following_strategy,
)
from backtest_engine import run_backtest

router = APIRouter(prefix="/backtest", tags=["backtest"])


StrategyName = Literal[
    "golden_cross",
    "rsi_bb",
    "macd_volume",
    "breakout",
    "trend_following",
]

STRATEGY_MAP = {
    "golden_cross": golden_cross_strategy,
    "rsi_bb": rsi_bollinger_strategy,
    "macd_volume": macd_volume_strategy,
    "breakout": breakout_strategy,
    "trend_following": trend_following_strategy,
}


class BacktestResponse(BaseModel):
    strategy: str
    ticker: str
    interval: str
    period: str
    total_return_pct: float
    total_trades: int
    win_rate: float
    profit_factor: float
    max_drawdown_pct: float
    sharpe_ratio: float
    initial_capital: float
    final_capital: float


@router.get("/run", response_model=BacktestResponse)
async def run_backtest_api(
    strategy: StrategyName,
    ticker: str = Query("KRW-BTC"),
    interval: str = Query("day"),
    count: int = Query(500, ge=50, le=2000),
    initial_capital: float = Query(10_000_000),
) -> BacktestResponse:
    """전략 백테스팅 실행"""
    df = pyupbit.get_ohlcv(ticker, interval=interval, count=count)
    if df is None or len(df) == 0:
        raise ValueError("데이터 조회 실패")

    signal_fn = STRATEGY_MAP[strategy]
    result = run_backtest(df, signal_fn=signal_fn, initial_capital=initial_capital)

    summary = result.summary()
    period = f"{df.index[0].strftime('%Y-%m-%d')} ~ {df.index[-1].strftime('%Y-%m-%d')}"

    return BacktestResponse(
        strategy=strategy,
        ticker=ticker,
        interval=interval,
        period=period,
        **summary,
    )
```

```
GET /backtest/run?strategy=golden_cross&ticker=KRW-BTC&count=500
```

```json
  "sharpe_ratio": 1.12,
  "initial_capital": 10000000,
  "final_capital": 14523000
}
```

## 10.6 10장 요약

- **백테스팅**은 실전 투입 전 반드시 거쳐야 하는 과정입니다.
- 핵심 지표: **총수익률, CAGR, MDD, 승률, 손익비, 샤프 지수**
- **MDD**는 전략의 심리적 내구도를 평가하는 중요한 지표입니다.
- TradingView의 **Strategy Tester**로 Pine Script 전략을 쉽게 테스트할 수 있습니다.
- Python으로 **직접 백테스팅 엔진**을 만들어 커스터마이징이 가능합니다.
- **거래 수수료와 슬리피지**를 반영해야 현실적인 결과가 나옵니다.
- **과최적화(Overfitting)**를 주의하고, 워크포워드 분석 등 추가 검증을 권장합니다.

> ⚠️ **백테스트 ≠ 실전**
> 아무리 백테스팅 결과가 좋아도, 미래 시장에서 동일한 성과를 낸다는 보장은 없습니다.
> 반드시 **모의투자 → 소액 실전 → 점진적 확대** 순서를 지키세요.
