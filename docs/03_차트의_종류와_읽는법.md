# 3장. 차트의 종류와 읽는 법

> 주식 차트는 가격의 움직임을 시각적으로 보여주는 그래프입니다.
> 이 장에서는 차트의 종류와 각 차트를 읽는 방법, 그리고 캔들스틱 패턴을 완전히 이해해봅니다.

---

## 3.1 차트의 기본 구성 요소

모든 차트에는 4가지 기본 가격 데이터가 있습니다:

| 용어 | 영어 | 의미 |
|------|------|------|
| **시가(Open)** | Open | 해당 기간의 시작 가격 |
| **고가(High)** | High | 해당 기간의 최고 가격 |
| **저가(Low)** | Low | 해당 기간의 최저 가격 |
| **종가(Close)** | Close | 해당 기간의 마지막 가격 |

이 4가지를 줄여서 **OHLC**라고 부릅니다.

**예시**: 삼성전자 2024년 1월 15일 일봉
- 시가(Open): 72,000원 (아침 9시에 72,000원에 시작)
- 고가(High): 73,500원 (장 중 최고 73,500원까지 올라감)
- 저가(Low): 71,200원 (장 중 최저 71,200원까지 내려감)
- 종가(Close): 73,000원 (오후 3시 30분에 73,000원에 마감)

## 3.2 라인 차트 (Line Chart)

### 개념
**종가(Close)만** 연결한 가장 단순한 차트입니다.

### 계산 방식
각 기간의 종가를 점으로 찍고, 이 점들을 직선으로 연결합니다.

```
가격(원)
73,000 ┤                    ●───●
72,500 ┤              ●────●
72,000 ┤        ●────●
71,500 ┤  ●────●
71,000 ┤
       └──┬──┬──┬──┬──┬──┬──┬──→ 시간
         1/8 1/9 1/10 1/11 1/12 1/15 1/16 1/17

각 점 = 해당 일의 종가
```

### 시각적 특징
- 가장 깔끔하고 읽기 쉬움
- 전체적인 추세를 파악하기 좋음

### 장점
- 직관적이고 심플함
- 큰 추세를 한눈에 파악
- 초보자가 처음 보기에 가장 편함

### 단점
- 시가, 고가, 저가 정보를 볼 수 없음
- 장 중 가격 변동 폭을 알 수 없음
- 세부적인 매매 타이밍 판단이 어려움

### TradingView에서 설정하기
1. 상단 메뉴바에서 차트 유형 아이콘 클릭
2. **"라인(Line)"** 선택

## 3.3 바 차트 (Bar Chart / OHLC Bar)

### 개념
OHLC(시가, 고가, 저가, 종가) 4가지 정보를 모두 표현하는 차트입니다.

### 계산 방식
하나의 바(막대)가 다음과 같이 구성됩니다:

```
      │         ← 고가(High) = 73,500원
      │
      │
  ────│         ← 시가(Open) = 72,000원 (왼쪽 가로선)
      │
      │────     ← 종가(Close) = 73,000원 (오른쪽 가로선)
      │
      │         ← 저가(Low) = 71,200원
```

- **세로선**: 고가~저가 범위
- **왼쪽 가로선**: 시가(Open)
- **오른쪽 가로선**: 종가(Close)

### 시각적 특징
- 종가 > 시가 → 상승 (보통 녹색/파란색)
- 종가 < 시가 → 하락 (보통 빨간색)

### 장점
- OHLC 4가지 정보를 모두 보여줌
- 가격 변동 범위를 파악 가능

### 단점
- 캔들스틱에 비해 시각적으로 구분이 어려움
- 상승/하락을 직관적으로 보기 힘듦

### TradingView에서 설정하기
1. 상단 메뉴바에서 차트 유형 아이콘 클릭
2. **"바(Bars)"** 선택

## 3.4 캔들스틱 차트 (Candlestick Chart)

### 개념
**가장 널리 사용되는 차트**입니다. 바 차트와 같은 OHLC 정보를 더 직관적으로 표현합니다.

### 계산 방식

**양봉 (상승, 종가 > 시가)**:
```
         │         ← 윗꼬리(Upper Shadow)
         │
    ┌────┴────┐    ← 종가(Close) = 73,000원
    │         │
    │  몸통    │    ← 몸통(Body) = 시가~종가 사이
    │ (빈/녹색)│
    └────┬────┘    ← 시가(Open) = 72,000원
         │
         │         ← 아랫꼬리(Lower Shadow)
```

**음봉 (하락, 종가 < 시가)**:
```
         │         ← 윗꼬리(Upper Shadow)
         │
    ┌────┴────┐    ← 시가(Open) = 73,000원
    │         │
    │  몸통    │    ← 몸통(Body) = 시가~종가 사이
    │ (채움/적)│
    └────┬────┘    ← 종가(Close) = 72,000원
         │
         │         ← 아랫꼬리(Lower Shadow)
```

**실제 숫자 예시**:

| 구분 | 양봉 예시 | 음봉 예시 |
|------|-----------|-----------|
| 시가(Open) | 72,000원 | 73,000원 |
| 고가(High) | 73,500원 | 73,500원 |
| 저가(Low) | 71,200원 | 71,200원 |
| 종가(Close) | 73,000원 | 72,000원 |
| 몸통 크기 | 1,000원(상승) | 1,000원(하락) |
| 윗꼬리 길이 | 500원 | 500원 |
| 아랫꼬리 길이 | 800원 | 800원 |

### 시각적 특징
- **양봉**: 보통 빈 사각형 또는 녹색/파란색 (한국에서는 빨간색이 상승)
- **음봉**: 보통 채워진 사각형 또는 빨간색 (한국에서는 파란색이 하락)

> ⚠️ **주의: 한국 vs 해외 색상 차이**
> - **한국 주식**: 상승 = 빨간색, 하락 = 파란색
> - **해외 주식/암호화폐**: 상승 = 녹색, 하락 = 빨간색
> - TradingView에서 색상은 설정에서 변경할 수 있습니다.

### 장점
- 상승/하락을 색상으로 직관적으로 구분
- 매수/매도 세력의 힘을 시각적으로 파악
- 다양한 패턴 분석 가능

### 단점
- 처음 보면 복잡하게 느껴질 수 있음
- 패턴 해석이 주관적일 수 있음

### TradingView에서 설정하기
1. 상단 메뉴바에서 차트 유형 아이콘 클릭
2. **"캔들(Candles)"** 선택 (기본값)

## 3.5 하이킨아시 차트 (Heikin-Ashi Chart)

### 개념
일반 캔들스틱을 **평균값으로 계산**하여 추세를 더 부드럽게 보여주는 차트입니다. "하이킨아시"는 일본어로 "평균 막대"라는 뜻입니다.

### 계산 방식
일반 캔들과 달리, 이전 캔들의 값을 사용하여 계산합니다:

```
하이킨아시 종가 = (시가 + 고가 + 저가 + 종가) ÷ 4
하이킨아시 시가 = (이전 하이킨아시 시가 + 이전 하이킨아시 종가) ÷ 2
하이킨아시 고가 = max(고가, 하이킨아시 시가, 하이킨아시 종가)
하이킨아시 저가 = min(저가, 하이킨아시 시가, 하이킨아시 종가)
```

**실제 숫자 예시**:

일반 캔들 데이터:
| 날짜 | 시가 | 고가 | 저가 | 종가 |
|------|------|------|------|------|
| 1/15 | 72,000 | 73,500 | 71,200 | 73,000 |
| 1/16 | 73,200 | 74,000 | 72,800 | 73,800 |

1/15 하이킨아시 계산:
- 종가 = (72,000 + 73,500 + 71,200 + 73,000) ÷ 4 = **72,425원**
- 시가 = 이전 값 없으면 (72,000 + 73,000) ÷ 2 = **72,500원**
- 고가 = max(73,500, 72,500, 72,425) = **73,500원**
- 저가 = min(71,200, 72,500, 72,425) = **71,200원**

1/16 하이킨아시 계산:
- 종가 = (73,200 + 74,000 + 72,800 + 73,800) ÷ 4 = **73,450원**
- 시가 = (72,500 + 72,425) ÷ 2 = **72,463원**
- 고가 = max(74,000, 72,463, 73,450) = **74,000원**
- 저가 = min(72,800, 72,463, 73,450) = **72,463원**

### 시각적 특징
- 상승 추세: 연속된 양봉 + 아랫꼬리 없음
- 하락 추세: 연속된 음봉 + 윗꼬리 없음
- 추세 전환: 짧은 몸통 + 긴 꼬리 (도지와 유사)

### 장점
- 추세를 깔끔하게 보여줌 (노이즈 감소)
- 추세 전환 시점을 파악하기 좋음
- 초보자도 추세를 쉽게 읽을 수 있음

### 단점
- **실제 가격을 보여주지 않음** (평균값이므로)
- 정확한 매수/매도 가격 결정에 부적합
- 갭(Gap)을 표시하지 않음

> ⚠️ **주의**
> 하이킨아시 차트는 **추세 파악용**으로만 사용하세요.
> 실제 주문 가격은 반드시 일반 캔들스틱 차트에서 확인해야 합니다.

### TradingView에서 설정하기
1. 상단 메뉴바에서 차트 유형 아이콘 클릭
2. **"하이킨아시(Heikin Ashi)"** 선택

## 3.7 캔들스틱 완전 해설

### 몸통(Body)의 의미

캔들의 **몸통 크기**는 매수/매도 세력의 힘을 나타냅니다.

| 몸통 크기 | 의미 |
|-----------|------|
| 긴 양봉(큰 몸통) | 매수세가 강함 → 강한 상승 |
| 긴 음봉(큰 몸통) | 매도세가 강함 → 강한 하락 |
| 짧은 몸통 | 매수/매도 세력이 비슷 → 방향 불확실 |
| 몸통 없음(도지) | 시가 = 종가 → 전환 가능성 |

### 꼬리(Shadow/Wick)의 의미

캔들의 **꼬리 길이**는 가격 변동의 흔적을 보여줍니다.

| 꼬리 위치 | 의미 |
|-----------|------|
| 긴 윗꼬리 | 높이 올라갔다가 밀려 내려옴 → 위에서 매도 세력이 강함 |
| 긴 아랫꼬리 | 많이 내려갔다가 다시 올라옴 → 아래에서 매수 세력이 강함 |
| 양쪽 긴 꼬리 | 위아래 모두 큰 변동 → 시장 불확실성이 큼 |
| 꼬리 없음 | 한 방향으로 강하게 움직임 → 매우 강한 추세 |

## 3.8 핵심 캔들 패턴 10가지

### 패턴 1: 도지(Doji)

```
      │
      │
    ──┼──      ← 시가 ≒ 종가 (몸통이 거의 없음)
      │
      │
```

- **형태**: 몸통이 거의 없고, 위아래 꼬리가 있음
- **의미**: 매수와 매도 세력이 팽팽하게 맞서고 있음
- **투자 해석**: **추세 전환의 신호**. 상승 추세 끝에 나오면 하락 전환 가능, 하락 추세 끝에 나오면 상승 전환 가능
- **실전 팁**: 도지 하나만으로 판단하지 말고, 다음 캔들의 방향을 확인하세요

### 패턴 2: 망치형(Hammer)

```
    ┌─┐
    │ │        ← 짧은 몸통 (위쪽)
    └┬┘
     │
     │         ← 긴 아랫꼬리 (몸통의 2~3배)
     │
```

- **형태**: 짧은 몸통 + 긴 아랫꼬리 + 윗꼬리 거의 없음
- **출현 위치**: **하락 추세의 바닥**
- **의미**: 많이 떨어졌지만 매수세가 가격을 다시 끌어올림
- **투자 해석**: **상승 전환 신호** (반등 가능성)
- **조건**: 아랫꼬리 길이가 몸통의 2배 이상일 때 신뢰도 높음
- **실전 팁**: 다음 날 양봉이 나오면 매수 신호 강화

### 패턴 3: 교수형(Hanging Man)

```
    ┌─┐
    │ │        ← 짧은 몸통 (위쪽)
    └┬┘
     │
     │         ← 긴 아랫꼬리
     │
```

- **형태**: 망치형과 **동일한 모양**이지만 출현 위치가 다름
- **출현 위치**: **상승 추세의 꼭대기**
- **의미**: 매도세가 나타나기 시작함
- **투자 해석**: **하락 전환 신호** (고점 경고)
- **실전 팁**: 같은 모양이지만 위치에 따라 정반대 의미! 맥락이 중요합니다

### 패턴 4: 역망치형(Inverted Hammer)

```
     │
     │         ← 긴 윗꼬리
     │
    ┌┴┐
    │ │        ← 짧은 몸통 (아래쪽)
    └─┘
```

- **형태**: 짧은 몸통 + 긴 윗꼬리 + 아랫꼬리 거의 없음
- **출현 위치**: **하락 추세의 바닥**
- **의미**: 매수세가 가격을 올리려 시도함
- **투자 해석**: **상승 전환 가능성** (약한 신호)
- **실전 팁**: 다음 날 양봉 확인 후 진입하는 것이 안전

### 패턴 5: 유성형(Shooting Star)

```
     │
     │         ← 긴 윗꼬리
     │
    ┌┴┐
    │ │        ← 짧은 몸통 (아래쪽)
    └─┘
```

- **형태**: 역망치형과 **동일한 모양**이지만 출현 위치가 다름
- **출현 위치**: **상승 추세의 꼭대기**
- **의미**: 많이 올라갔지만 매도세에 밀려 내려옴
- **투자 해석**: **하락 전환 신호** (강력한 경고)
- **실전 팁**: 거래량이 많을수록 신뢰도 높음

### 패턴 6: 장악형 양봉(Bullish Engulfing)

```
     이전      현재
    ┌──┐
    │음│    ┌──────┐
    │봉│    │      │
    └──┘    │ 양봉  │    ← 현재 양봉이 이전 음봉을 완전히 감싸
            │      │
            └──────┘
```

- **형태**: 이전 음봉을 현재 양봉이 완전히 감싸는 형태 (2개 캔들)
- **출현 위치**: **하락 추세의 바닥**
- **의미**: 매수세가 매도세를 압도
- **투자 해석**: **강한 상승 전환 신호**
- **조건**: 현재 양봉의 몸통이 이전 음봉 몸통을 완전히 포함해야 함
- **실전 팁**: 하락이 오래 지속된 후 나올수록 신뢰도 높음

### 패턴 7: 장악형 음봉(Bearish Engulfing)

```
     이전      현재
            ┌──────┐
    ┌──┐    │      │
    │양│    │ 음봉  │    ← 현재 음봉이 이전 양봉을 완전히 감싸
    │봉│    │      │
    └──┘    └──────┘
```

- **형태**: 이전 양봉을 현재 음봉이 완전히 감싸는 형태 (2개 캔들)
- **출현 위치**: **상승 추세의 꼭대기**
- **의미**: 매도세가 매수세를 압도
- **투자 해석**: **강한 하락 전환 신호**
- **실전 팁**: 상승이 오래 지속된 후 나올수록 신뢰도 높음

### 패턴 8: 샛별형(Morning Star)

```
   1일차    2일차    3일차
   ┌──┐
   │음│     ┌┐
   │봉│     ││     ┌──┐
   │  │     └┘     │양│
   └──┘    (도지)   │봉│
                    └──┘
```

- **형태**: 긴 음봉 → 도지(또는 짧은 캔들) → 긴 양봉 (3개 캔들)
- **출현 위치**: **하락 추세의 바닥**
- **의미**: 하락 → 매수/매도 균형 → 반등 시작
- **투자 해석**: **강력한 상승 전환 신호**
- **실전 팁**: 3일차 양봉의 거래량이 많을수록 신뢰도 높음

### 패턴 9: 저녁별형(Evening Star)

```
   1일차    2일차    3일차
            ┌┐
   ┌──┐     ││
   │양│     └┘     ┌──┐
   │봉│    (도지)   │음│
   │  │            │봉│
   └──┘            └──┘
```

- **형태**: 긴 양봉 → 도지(또는 짧은 캔들) → 긴 음봉 (3개 캔들)
- **출현 위치**: **상승 추세의 꼭대기**
- **의미**: 상승 → 매수/매도 균형 → 하락 시작
- **투자 해석**: **강력한 하락 전환 신호**
- **실전 팁**: 상승이 과열(RSI 70 이상)된 상태에서 나타나면 더 신뢰

### 패턴 10: 십자 도지(Long-legged Doji)

```
      │
      │
      │
    ──┼──      ← 시가 ≒ 종가
      │
      │
      │
```

- **형태**: 몸통 거의 없음 + 위아래 매우 긴 꼬리
- **의미**: 극심한 변동성 속에서 매수/매도 균형
- **투자 해석**: **중요한 전환점**. 시장이 중대한 결정을 앞두고 있음
- **실전 팁**: 중요 지지/저항선 근처에서 나타나면 전환 가능성 매우 높음
