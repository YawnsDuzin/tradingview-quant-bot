> 리스크 관리는 퀀트 투자의 가장 중요한 요소입니다.

## 11.1 왜 리스크 관리가 중요한가

### 1장에서 배운 손실 복구의 어려움

| 손실률 | 원금 회복에 필요한 수익률 |
|--------|--------------------------|
| -10% | +11.1% |
| -20% | +25.0% |
| -30% | +42.9% |
| -50% | +100.0% |

손실이 커지면 원금 회복에 드는 수익률은 **기하급수적**으로 증가합니다.

### 리스크 관리의 핵심 원칙

1. **한 번의 큰 손실은 수십 번의 작은 수익을 무효화시킬 수 있다**
2. **모든 거래는 실패할 수 있다는 가정 하에 포지션 크기를 결정한다**
3. **손실은 예측할 수 없지만, 손실의 크기는 제어할 수 있다**

## 11.2 포지션 사이징(Position Sizing)이란

### 정의

**포지션 사이징**은 **한 번의 거래에 얼마의 자금을 투입할 것인가**를 결정하는 과정입니다.

**예시**:
- 총 자산 1,000만원
- 한 번의 거래에 10% (= 100만원) 사용
- 이것이 "포지션 사이징"

### 포지션 사이징의 3가지 방법

#### 방법 1: 고정 금액 (Fixed Amount)

항상 같은 금액을 사용합니다.

```python
def fixed_amount_sizing(
    cash: float,
    fixed_amount: float = 1_000_000,
) -> float:
    """고정 금액 포지션"""
    return min(fixed_amount, cash)
```

- **장점**: 단순함
- **단점**: 자산 증가/감소를 반영하지 않음

#### 방법 2: 고정 비율 (Fixed Percentage)

자산의 일정 비율을 사용합니다.

```python
def fixed_percentage_sizing(
    cash: float,
    percentage: float = 10.0,  # 10%
) -> float:
    """고정 비율 포지션"""
    return cash * (percentage / 100.0)
```

- **장점**: 자산 규모에 비례하여 포지션 조정
- **단점**: 리스크가 다른 종목에 동일 비율 적용

#### 방법 3: 변동성 기반 (Volatility-Based)

종목의 변동성에 따라 포지션 크기를 조정합니다.

```python
import pandas as pd
import pandas_ta as ta


def atr_based_sizing(
    df: pd.DataFrame,
    cash: float,
    risk_per_trade_pct: float = 2.0,  # 거래당 최대 2% 손실
    atr_multiplier: float = 2.0,
) -> float:
    """
    ATR 기반 포지션 사이징

    아이디어: 변동성이 큰 종목은 작은 포지션, 작은 종목은 큰 포지션

    Args:
        df: OHLCV DataFrame
        cash: 사용 가능 자산
        risk_per_trade_pct: 한 거래당 최대 손실 비율 (%)
        atr_multiplier: ATR 배수 (손절 거리)

    Returns:
        매수할 금액
    """
    atr = ta.atr(df["high"], df["low"], df["close"], length=14)
    latest_atr = float(atr.iloc[-1])
    latest_close = float(df["close"].iloc[-1])

    # 손절 거리 (원)
    stop_distance = latest_atr * atr_multiplier

    # 허용 손실 금액
    risk_amount = cash * (risk_per_trade_pct / 100.0)

    # 포지션 크기 = 허용 손실 ÷ 손절 거리 × 가격
    position_size = (risk_amount / stop_distance) * latest_close
    return min(position_size, cash)
```

## 11.3 켈리 공식 (Kelly Criterion)

### 켈리 공식이란?

**켈리 공식**은 **수학적으로 최적의 투자 비율**을 계산하는 공식입니다. 1956년 존 켈리(John Kelly)가 발표했습니다.

### 공식

```
f* = (bp - q) / b

where:
  f* = 최적 투자 비율
  b  = 손익비 (평균 수익 / 평균 손실)
  p  = 승률
  q  = 패배율 (1 - p)
```

### 실제 숫자 예시

가정: 어떤 전략의 백테스팅 결과
- 승률(p) = 60% = 0.6
- 패배율(q) = 40% = 0.4
- 평균 수익 = 3%
- 평균 손실 = 2%
- 손익비(b) = 3 / 2 = 1.5

켈리 공식 적용:
- f* = (1.5 × 0.6 - 0.4) / 1.5
- f* = (0.9 - 0.4) / 1.5
- f* = 0.5 / 1.5
- f* = **0.333 = 33.3%**

**해석**: 한 번의 거래에 자산의 **33.3%**를 투입하는 것이 수학적 최적.

### 켈리 공식의 Python 구현

```python
"""
켈리 공식을 이용한 포지션 사이징
"""
from __future__ import annotations


def kelly_fraction(
    win_rate: float,
    win_loss_ratio: float,
) -> float:
    """
    켈리 공식으로 최적 투자 비율 계산

    Args:
        win_rate: 승률 (0.0 ~ 1.0)
        win_loss_ratio: 손익비 (평균 수익 / 평균 손실)

    Returns:
        최적 투자 비율 (0.0 ~ 1.0)
    """
    if win_loss_ratio <= 0:
        return 0.0

    q = 1.0 - win_rate
    f = (win_loss_ratio * win_rate - q) / win_loss_ratio
    return max(0.0, f)  # 음수면 0 (투자하지 말 것)


def fractional_kelly(
    win_rate: float,
    win_loss_ratio: float,
    fraction: float = 0.5,
) -> float:
    """
    분할 켈리 (Kelly / 2, Kelly / 4 등)

    풀 켈리는 변동성이 크므로 실전에서는 절반 이하를 사용하는 것이 일반적

    Args:
        win_rate: 승률
        win_loss_ratio: 손익비
        fraction: 켈리 비율의 몇 분의 몇을 사용할 것인가 (0.5 = 하프 켈리)

    Returns:
        조정된 투자 비율
    """
    full_kelly = kelly_fraction(win_rate, win_loss_ratio)
    return full_kelly * fraction


if __name__ == "__main__":
    # 예시: 승률 60%, 손익비 1.5
    full = kelly_fraction(0.6, 1.5)
    half = fractional_kelly(0.6, 1.5, fraction=0.5)
    quarter = fractional_kelly(0.6, 1.5, fraction=0.25)

    print(f"Full Kelly:    {full*100:.1f}%")
    print(f"Half Kelly:    {half*100:.1f}%")
    print(f"Quarter Kelly: {quarter*100:.1f}%")
```

**출력**:
```
Full Kelly:    33.3%
Half Kelly:    16.7%
Quarter Kelly: 8.3%
```

### ⚠️ 켈리 공식의 함정

1. **과거 통계를 기반으로 계산** → 미래 성과가 다를 수 있음
2. **풀 켈리는 변동성이 매우 큼** → 심리적 부담
3. **음수 기댓값에서는 투자하지 말 것** → 공식이 음수를 반환

> 💡 **실전 권장**
> 대부분의 전문가는 **하프 켈리(Kelly / 2) 또는 쿼터 켈리(Kelly / 4)**를 권장합니다.
> 풀 켈리는 이론적 최적이지만, 실전에서는 과도한 리스크입니다.

## 11.4 손절매의 중요성과 설정 기준

### 손절매(Stop Loss)란?

**손절매**는 **손실이 일정 수준에 도달하면 자동으로 포지션을 청산**하는 것입니다.

### 왜 반드시 손절매를 해야 하는가?

1. **큰 손실 방지**: 작은 손실을 확정하고 큰 손실을 피함
2. **감정 배제**: 미리 정한 규칙대로 기계적 실행
3. **자본 보존**: 살아남아야 다음 기회를 잡을 수 있음

### 손절매 설정 방법

#### 방법 1: 고정 비율 손절 (Fixed Percentage Stop)

```python
def fixed_percent_stop(
    entry_price: float,
    stop_loss_pct: float = 5.0,
) -> float:
    """
    진입가 대비 고정 비율 손절가 계산

    Args:
        entry_price: 진입 가격
        stop_loss_pct: 손절 비율 (%)

    Returns:
        손절 가격
    """
    return entry_price * (1 - stop_loss_pct / 100.0)
```

**예시**: 100,000원에 매수, 손절 5%
- 손절가 = 100,000 × 0.95 = **95,000원**

#### 방법 2: ATR 기반 손절 (Volatility Stop)

```python
import pandas as pd
import pandas_ta as ta


def atr_stop_loss(
    df: pd.DataFrame,
    entry_price: float,
    atr_length: int = 14,
    atr_multiplier: float = 2.0,
) -> float:
    """
    ATR 기반 동적 손절가

    변동성이 클수록 손절 거리도 넓어짐

    Args:
        df: OHLCV DataFrame
        entry_price: 진입 가격
        atr_length: ATR 기간
        atr_multiplier: ATR 배수

    Returns:
        손절 가격
    """
    atr = ta.atr(df["high"], df["low"], df["close"], length=atr_length)
    latest_atr = float(atr.iloc[-1])
    return entry_price - (latest_atr * atr_multiplier)
```

#### 방법 3: 지지선 기반 손절

```python
def support_based_stop(
    support_price: float,
    buffer_pct: float = 1.0,
) -> float:
    """
    지지선 아래에 버퍼를 두고 손절가 설정

    Args:
        support_price: 주요 지지선 가격
        buffer_pct: 지지선 아래 여유 공간 (%)

    Returns:
        손절 가격
    """
    return support_price * (1 - buffer_pct / 100.0)
```

#### 방법 4: Trailing Stop (추적 손절)

```python
class TrailingStop:
    """
    추적 손절: 고점이 갱신될 때마다 손절가도 올림

    상승 추세에서 수익을 최대화하면서 하락 시 자동 청산
    """

    def __init__(self, entry_price: float, trailing_pct: float = 5.0) -> None:
        self.entry_price = entry_price
        self.trailing_pct = trailing_pct
        self.highest_price = entry_price
        self.stop_price = entry_price * (1 - trailing_pct / 100.0)

    def update(self, current_price: float) -> bool:
        """
        현재 가격 업데이트 및 손절 여부 판단

        Returns:
            손절 필요 여부 (True = 매도)
        """
        if current_price > self.highest_price:
            self.highest_price = current_price
            self.stop_price = current_price * (1 - self.trailing_pct / 100.0)

        return current_price <= self.stop_price
```

**사용 예시**:
```python
ts = TrailingStop(entry_price=100_000, trailing_pct=5.0)

# 가격 상승: 손절가도 상승
ts.update(110_000)  # highest=110,000, stop=104,500
ts.update(120_000)  # highest=120,000, stop=114,000

# 가격 하락: 손절 발동
should_exit = ts.update(113_000)  # stop=114,000 > current → True
```

## 11.5 분산 투자 원칙

### 왜 분산 투자해야 하는가?

**"달걀을 한 바구니에 담지 마라"**

한 종목에 올인하면:
- 해당 종목이 망하면 전액 손실
- 감정적 압박 증가
- 리스크 집중

### 분산의 4가지 축

#### 1. 종목 분산

```python
"""
여러 종목에 고르게 분산
"""
def equal_weight_allocation(
    symbols: list[str],
    total_capital: float,
) -> dict[str, float]:
    """동일 비중 포트폴리오"""
    n = len(symbols)
    per_symbol = total_capital / n
    return {symbol: per_symbol for symbol in symbols}
```

**예시**: 1,000만원을 5종목에 고르게 → 각 200만원

#### 2. 산업 분산

- 반도체 + IT + 바이오 + 소비재 + 금융 등
- 특정 산업이 불황이어도 다른 산업이 보완

#### 3. 자산군 분산

```python
"""
코인과 주식 비중을 나눠 투자
"""
def cross_asset_allocation(
    total_capital: float,
    crypto_pct: float = 30.0,
    stock_pct: float = 60.0,
    cash_pct: float = 10.0,
) -> dict[str, float]:
    """자산군별 분산"""
    return {
        "crypto": total_capital * (crypto_pct / 100),
        "stock": total_capital * (stock_pct / 100),
        "cash": total_capital * (cash_pct / 100),
    }
```

#### 4. 시간 분산

- 한 번에 다 사지 말고 나눠서 매수 (DCA: Dollar Cost Averaging)
- 고점 매수 리스크 감소

## 11.6 리스크 관리 통합 모듈

위의 모든 내용을 하나의 Python 모듈로 통합합니다.

### `risk_management.py` 전체 코드

```python
"""
종합 리스크 관리 모듈
"""
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Literal

import pandas as pd
import pandas_ta as ta


@dataclass
class RiskConfig:
    """리스크 관리 설정"""

    # 포지션 한도
    max_position_pct: float = 20.0          # 종목당 최대 포지션 (%)
    max_total_exposure_pct: float = 80.0    # 전체 투자 비율 (%)

    # 거래당 리스크
    risk_per_trade_pct: float = 2.0         # 거래당 최대 손실 (%)

    # 손절
    stop_loss_pct: float = 5.0              # 기본 손절 %
    atr_multiplier: float = 2.0             # ATR 손절 배수

    # 일일 한도
    daily_loss_limit_pct: float = 5.0       # 일일 최대 손실 (%)
    daily_trade_limit: int = 10             # 일일 최대 거래 수


@dataclass
class Position:
    """포지션 정보"""

    symbol: str
    entry_price: float
    quantity: float
    stop_price: float
    entry_time: str
    trailing_enabled: bool = False
    highest_price: float = field(default=0.0)

    def update_trailing(self, current_price: float, trailing_pct: float) -> None:
        """Trailing Stop 업데이트"""
        if not self.trailing_enabled:
            return
        if current_price > self.highest_price:
            self.highest_price = current_price
            self.stop_price = current_price * (1 - trailing_pct / 100.0)

    def should_stop(self, current_price: float) -> bool:
        """손절 조건 확인"""
        return current_price <= self.stop_price

    @property
    def unrealized_pnl_pct(self) -> float:
        """미실현 손익률 계산용 (현재가 필요)"""
        return 0.0  # 외부에서 계산


class RiskManager:
    """종합 리스크 관리자"""

    def __init__(self, config: RiskConfig | None = None) -> None:
        self.config = config or RiskConfig()
        self.positions: dict[str, Position] = {}
        self.daily_pnl: float = 0.0
        self.daily_trade_count: int = 0

    # ---------- 포지션 사이징 ----------

    def calculate_position_size(
        self,
        total_capital: float,
        current_price: float,
        df: pd.DataFrame | None = None,
        method: Literal["fixed_pct", "atr", "kelly"] = "fixed_pct",
        **kwargs,
    ) -> float:
        """
        포지션 크기 계산

        Args:
            total_capital: 총 자산
            current_price: 현재가
            df: OHLCV DataFrame (ATR 방식일 때)
            method: "fixed_pct" / "atr" / "kelly"

        Returns:
            매수할 금액 (원화)
        """
        # 일일 한도 체크
        if not self._check_daily_limit(total_capital):
            return 0.0

        # 전체 노출 한도 체크
        if self._total_exposure_pct(total_capital) >= self.config.max_total_exposure_pct:
            return 0.0

        # 방식별 계산
        if method == "fixed_pct":
            return total_capital * (self.config.max_position_pct / 100.0)

        elif method == "atr" and df is not None:
            atr = ta.atr(df["high"], df["low"], df["close"], length=14)
            latest_atr = float(atr.iloc[-1])
            stop_distance = latest_atr * self.config.atr_multiplier
            risk_amount = total_capital * (self.config.risk_per_trade_pct / 100.0)
            position_value = (risk_amount / stop_distance) * current_price
            max_allowed = total_capital * (self.config.max_position_pct / 100.0)
            return min(position_value, max_allowed)

        elif method == "kelly":
            win_rate = kwargs.get("win_rate", 0.5)
            win_loss_ratio = kwargs.get("win_loss_ratio", 1.5)
            kelly = kelly_fraction(win_rate, win_loss_ratio) * 0.5  # Half Kelly
            return total_capital * min(kelly, self.config.max_position_pct / 100.0)

        return 0.0

    # ---------- 손절 계산 ----------

    def calculate_stop_price(
        self,
        entry_price: float,
        df: pd.DataFrame | None = None,
        method: Literal["fixed_pct", "atr"] = "fixed_pct",
    ) -> float:
        """손절가 계산"""
        if method == "atr" and df is not None:
            atr = ta.atr(df["high"], df["low"], df["close"], length=14)
            latest_atr = float(atr.iloc[-1])
            return entry_price - (latest_atr * self.config.atr_multiplier)
        return entry_price * (1 - self.config.stop_loss_pct / 100.0)

    # ---------- 포지션 관리 ----------

    def add_position(self, position: Position) -> None:
        self.positions[position.symbol] = position
        self.daily_trade_count += 1

    def remove_position(self, symbol: str, pnl: float = 0.0) -> None:
        if symbol in self.positions:
            del self.positions[symbol]
        self.daily_pnl += pnl

    def _total_exposure_pct(self, total_capital: float) -> float:
        """현재 포트폴리오 노출 비율"""
        if total_capital == 0:
            return 0.0
        exposure = sum(p.entry_price * p.quantity for p in self.positions.values())
        return exposure / total_capital * 100

    def _check_daily_limit(self, total_capital: float) -> bool:
        """일일 손실/거래 한도 확인"""
        # 일일 손실 한도
        if self.daily_pnl < -total_capital * self.config.daily_loss_limit_pct / 100:
            return False
        # 일일 거래 한도
        if self.daily_trade_count >= self.config.daily_trade_limit:
            return False
        return True

    def reset_daily_stats(self) -> None:
        """일일 통계 초기화 (매일 00:00에 호출)"""
        self.daily_pnl = 0.0
        self.daily_trade_count = 0


def kelly_fraction(win_rate: float, win_loss_ratio: float) -> float:
    """켈리 공식"""
    if win_loss_ratio <= 0:
        return 0.0
    q = 1.0 - win_rate
    f = (win_loss_ratio * win_rate - q) / win_loss_ratio
    return max(0.0, f)
```

## 11.7 FastAPI에 리스크 관리 통합

9장의 `signal_service`에 리스크 관리 레이어를 추가합니다.

```python
"""
signal.py에 리스크 체크 추가 예시
"""
from app.services.risk_management import RiskManager, RiskConfig

class SignalService:
    def __init__(self) -> None:
        self.risk_manager = RiskManager(RiskConfig())
        # ... 기존 코드

    async def _execute_upbit(self, alert: TradingViewAlert) -> dict | None:
        """업비트 매매 실행 (리스크 체크 추가)"""
        broker = await self.get_upbit()

        if alert.action == "BUY":
            cash = await broker.get_krw_balance()

            # 리스크 관리자에게 크기 계산 요청
            position_size = self.risk_manager.calculate_position_size(
                total_capital=cash,
                current_price=alert.price,
                method="fixed_pct",
            )

            if position_size <= 0:
                logger.warning("리스크 한도로 인해 매수 거부")
                return None

            pct = position_size / cash if cash > 0 else 0
            return await broker.buy_market_pct(alert.symbol, pct)

        elif alert.action in ("SELL", "CLOSE"):
            return await broker.sell_market_all(alert.symbol)
        return None
```

## 11.8 11장 요약

- **리스크 관리**는 퀀트 투자의 **가장 중요한** 요소입니다.
- **포지션 사이징**: 한 거래에 투입할 금액을 결정 (고정 금액/고정 비율/변동성 기반)
- **켈리 공식**: 수학적 최적 투자 비율. 실전에서는 **하프 켈리** 권장
- **손절매**: 반드시 사전에 정해진 기준으로 실행 (고정 비율/ATR/Trailing Stop)
- **분산 투자**: 종목/산업/자산군/시간 4가지 축으로 분산
- **일일 손실 한도, 거래 한도**를 두어 감정적 매매 방지
- `RiskManager` 클래스로 모든 리스크 정책을 하나의 모듈에서 관리

> ⚠️ **절대 원칙**
> - 한 거래에 **자산의 20% 이상** 투입하지 마세요
> - 한 거래당 최대 손실은 **총 자산의 2% 이하**로 제한하세요
> - **손절매 없는 전략은 전략이 아닙니다**
