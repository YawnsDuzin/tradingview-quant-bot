# 2장. TradingView 시작하기

> TradingView가 무엇인지, 왜 써야 하는지, 회원가입부터 기본 화면 사용법까지 하나씩 배워봅니다.

---

## 2.1 TradingView란 무엇이고 왜 써야 하는가

### TradingView 소개

**TradingView**는 전 세계에서 가장 인기 있는 차트 분석 플랫폼입니다.

쉽게 말하면:
> 주식, 코인, 외환 등의 가격 차트를 **무료로** 볼 수 있고,
> 다양한 분석 도구를 사용할 수 있으며,
> 특정 조건이 충족되면 **자동으로 알림**을 보내주는 서비스입니다.

### TradingView를 써야 하는 이유

| 장점 | 설명 |
|------|------|
| **무료 사용 가능** | 기본 기능은 무료, 유료 플랜 없이도 차트 분석 가능 |
| **웹 기반** | 설치 없이 웹 브라우저에서 바로 사용 |
| **다양한 시장 지원** | 한국 주식, 미국 주식, 암호화폐, 외환, 원자재 등 |
| **수백 개의 지표** | 이동평균, RSI, MACD 등 기술적 지표 기본 내장 |
| **Pine Script** | 나만의 지표/전략을 직접 프로그래밍 가능 |
| **Alert 기능** | 조건 충족 시 이메일, 팝업, **Webhook** 알림 |
| **소셜 기능** | 다른 투자자의 분석을 보고 배울 수 있음 |
| **Webhook 지원** | 외부 서버(FastAPI)와 연동하여 **자동매매** 가능 |

> 💡 **핵심 요약**
> TradingView는 차트 분석 + 지표 활용 + Alert/Webhook 기능을 제공하여,
> 우리가 만들 자동매매 시스템의 "눈" 역할을 합니다.

## 2.2 회원가입 방법

### 단계별 가입 절차

**방법 1: 이메일로 가입**

1. 웹 브라우저에서 **tradingview.com** 접속
2. 우측 상단의 **"시작하기"** 또는 **"Get started"** 버튼 클릭
3. **"이메일"** 탭 선택
4. 이메일 주소 입력 → **"이메일로 계속"** 클릭
5. 사용자 이름(닉네임) 설정
6. 비밀번호 설정 (8자 이상, 영문+숫자 조합 권장)
7. 이용약관 동의 체크
8. **"계정 만들기"** 클릭
9. 입력한 이메일로 인증 메일 수신 → 인증 링크 클릭
10. 가입 완료!

**방법 2: 소셜 로그인 (더 간편)**

1. 웹 브라우저에서 **tradingview.com** 접속
2. 우측 상단의 **"시작하기"** 클릭
3. 아래 소셜 로그인 버튼 중 하나 선택:
   - **Google 계정** (추천 - 가장 간편)
   - **Apple 계정**
   - **Facebook 계정**
4. 해당 서비스 로그인 화면에서 인증
5. TradingView 사용자 이름 설정
6. 가입 완료!

> ⚠️ **주의**
> 소셜 로그인 시 사용하는 계정의 보안이 중요합니다.
> 반드시 2단계 인증(2FA)이 설정된 계정을 사용하세요.

## 2.3 요금제 종류 전체 비교

TradingView는 무료(Free) 플랜과 4가지 유료 플랜을 제공합니다.

### 요금제 상세 비교표

| 기능 | Free | Essential | Plus | Premium | Ultimate |
|------|------|-----------|------|---------|----------|
| **월 요금 (USD)** | 무료 | ~$12.95 | ~$24.95 | ~$49.95 | ~$69.95 |
| **연 요금 (USD/월)** | 무료 | ~$12.95 | ~$24.95 | ~$49.95 | ~$69.95 |
| **차트에 지표 수** | 2개 | 5개 | 10개 | 25개 | 30개+ |
| **동시 차트 레이아웃** | 1개 | 2개 | 4개 | 8개 | 16개 |
| **저장 가능 차트** | 1개 | 5개 | 10개 | 무제한 | 무제한 |
| **Alert(알림) 수** | 5개 | 20개 | 100개 | 400개 | 800개 |
| **Webhook Alert** | **불가** | **불가** | **가능** | **가능** | **가능** |
| **초단위 차트** | 불가 | 불가 | 가능 | 가능 | 가능 |
| **광고** | 있음 | 없음 | 없음 | 없음 | 없음 |
| **Pine Script 지표** | 1개 | 2개 | 5개 | 10개 | 20개+ |
| **고객 지원** | 기본 | 일반 | 우선 | 최우선 | 전담 |

> ⚠️ **중요: 요금제는 수시로 변경될 수 있습니다!**
> 위 가격은 참고용이며, 정확한 최신 가격은 tradingview.com/pricing 에서 확인하세요.
> 연간 결제 시 상당한 할인이 적용됩니다.

### 초보자 추천 요금제

**단계별 추천**:

1. **처음 시작**: **Free (무료)** 플랜
   - 차트 보는 법, 지표 사용법을 익히기에 충분
   - 2개의 지표, 5개의 알림으로 기본 학습 가능

2. **학습 단계 (1~3개월)**: **Free** 유지
   - 차트 분석과 지표를 배우는 동안은 무료로 충분
   - TradingView 커뮤니티의 무료 지표 활용

3. **자동매매 연동 시작**: **Plus 이상** 필수
   - Webhook Alert은 **Plus 플랜부터** 사용 가능
   - 이것이 FastAPI 서버와 연동하는 핵심 기능

> 💡 **핵심 요약**
> - 학습 단계: **Free** (무료)로 충분
> - 자동매매 연동: **Plus** 이상 필수 (Webhook Alert 기능 필요)
> - TradingView는 자주 할인 프로모션을 진행하니, 블랙프라이데이/사이버먼데이를 노리면 최대 60% 할인 가능

## 2.4 기본 화면 구성 설명

TradingView에 로그인하면 다음과 같은 화면이 나타납니다.

```
┌─────────────────────────────────────────────────────────────────┐
│  ① 상단 메뉴바                                                   │
│  [로고] [검색창] [시간프레임] [차트유형] [지표] [전략] [알림] [설정] │
├──────┬──────────────────────────────────────────────┬───────────┤
│      │                                              │           │
│  ②   │              ④ 메인 차트 영역                 │  ⑤        │
│  그   │                                              │  주문     │
│  리   │         (여기에 가격 차트가 표시됩니다)          │  패널     │
│  기   │                                              │           │
│  도   │                                              │           │
│  구   │                                              │           │
│  바   │──────────────────────────────────────────────│           │
│      │              ③ 하단 패널                       │           │
│      │  [Pine Editor] [전략 테스터] [거래 패널]        │           │
├──────┴──────────────────────────────────────────────┴───────────┤
│  ⑥ 하단 상태바: [서버 시간] [인터넷 상태]                          │
└─────────────────────────────────────────────────────────────────┘
```

### 각 영역 상세 설명

#### ① 상단 메뉴바
- **검색창**: 종목을 검색하는 곳 (예: "삼성전자", "BTCUSDT")
- **시간프레임**: 캔들 1개가 나타내는 시간 (1분, 5분, 1시간, 1일 등)
- **차트 유형**: 캔들스틱, 라인, 바 등 차트 종류 선택
- **지표(Indicators)**: 이동평균선, RSI, MACD 등 추가
- **Alert(알림)**: 조건부 알림 설정

#### ② 왼쪽 그리기 도구바
- 추세선, 수평선, 피보나치 등 그리기 도구
- 지지선/저항선을 직접 그릴 때 사용
- 5장에서 자세히 다룹니다

#### ③ 하단 패널
- **Pine Editor**: Pine Script 코드를 작성하는 곳 (7장에서 다룸)
- **전략 테스터(Strategy Tester)**: 백테스트 결과를 보는 곳 (10장에서 다룸)
- **거래 패널**: 연동된 브로커를 통한 직접 거래 (참고용)

#### ④ 메인 차트 영역
- 가격 차트가 표시되는 핵심 영역
- 마우스 휠로 확대/축소
- 드래그로 좌우 이동
- 오른쪽 가격축: 현재 가격 표시
- 하단 시간축: 날짜/시간 표시

#### ⑤ 우측 패널
- 워치리스트: 관심 종목 목록
- 뉴스, 캘린더 등 부가 정보

## 2.5 한국 주식 및 암호화폐 종목 검색하는 방법

### 한국 주식 검색

1. 상단 **검색창** 클릭 (또는 키보드에서 아무 글자 입력)
2. 종목명 또는 종목코드 입력
   - 예: "삼성전자" 또는 "005930"
3. 검색 결과에서 거래소 확인
   - **KRX** = 한국거래소 (실시간 데이터, 유료)
   - **KOSPI** / **KOSDAQ** 표시 확인
4. 원하는 종목 클릭하면 차트가 표시됨

> ⚠️ **주의: 한국 주식 실시간 데이터**
> TradingView에서 한국 주식은 기본적으로 **15분 지연** 데이터입니다.
> 실시간 데이터를 보려면 별도의 거래소 데이터 구독이 필요할 수 있습니다.
> 학습 목적이라면 지연 데이터로도 충분합니다.

### 암호화폐 검색

1. 상단 **검색창** 클릭
2. 코인 심볼 입력
   - 비트코인: "BTCUSDT" 또는 "BTCKRW"
   - 이더리움: "ETHUSDT" 또는 "ETHKRW"
   - 리플: "XRPUSDT" 또는 "XRPKRW"
3. 거래소 선택
   - **UPBIT**: 업비트 (원화 거래)
   - **BINANCE**: 바이낸스 (USDT 거래)
   - **BITHUMB**: 빗썸 (원화 거래)
4. 원하는 거래소의 종목 클릭

### 자주 쓰는 심볼 정리

| 종목 | TradingView 심볼 | 거래소 |
|------|-------------------|--------|
| 삼성전자 | KRX:005930 | 한국거래소 |
| SK하이닉스 | KRX:000660 | 한국거래소 |
| 카카오 | KRX:035720 | 한국거래소 |
| 비트코인(원화) | UPBIT:BTCKRW | 업비트 |
| 이더리움(원화) | UPBIT:ETHKRW | 업비트 |
| 비트코인(달러) | BINANCE:BTCUSDT | 바이낸스 |
| 애플 | NASDAQ:AAPL | 나스닥 |
| 테슬라 | NASDAQ:TSLA | 나스닥 |

### 워치리스트(관심종목) 추가하기

1. 종목을 검색하여 차트에 표시
2. 우측 패널에서 **워치리스트** 탭 클릭
3. 상단의 **"+"** 버튼 클릭
4. 종목 심볼 입력 후 추가
5. 또는 차트에서 우클릭 → **"워치리스트에 추가"** 선택

**추천 워치리스트 구성 (초보자)**:
- 한국 대형주 3~5개 (삼성전자, SK하이닉스, 현대차 등)
- 주요 암호화폐 2~3개 (BTC, ETH, XRP)
- 미국 대형주 2~3개 (AAPL, TSLA, NVDA)

### 시간프레임 설정

차트에서 **시간프레임**은 캔들 1개가 나타내는 시간입니다.

| 시간프레임 | 캔들 1개 = | 주로 사용하는 투자 스타일 |
|-----------|-----------|------------------------|
| 1분, 5분 | 1분, 5분 | 스캘핑, 초단기 트레이딩 |
| 15분, 30분 | 15분, 30분 | 데이트레이딩 |
| 1시간, 4시간 | 1시간, 4시간 | 스윙트레이딩 |
| 1일(D) | 하루 | 단기~중기 투자 |
| 1주(W) | 한 주 | 중기~장기 투자 |
| 1월(M) | 한 달 | 장기 투자 |

**설정 방법**:
1. 상단 메뉴바에서 시간프레임 버튼 클릭
2. 원하는 시간 선택
3. 또는 키보드 단축키 사용:
   - `1` → 1분
   - `5` → 5분
   - `D` → 1일
   - `W` → 1주
   - `M` → 1월

> 💡 **핵심 요약**
> - 초보자는 **일봉(1D)**부터 시작하세요. 큰 그림을 보는 것이 먼저입니다.
> - 자동매매 시스템에서는 보통 **15분~4시간** 봉을 많이 사용합니다.
> - 시간프레임이 짧을수록 노이즈(의미 없는 변동)가 많아 초보자에게 어렵습니다.
