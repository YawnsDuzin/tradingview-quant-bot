# 1장. 주식 투자 기초 개념

> 주식이 무엇인지, 투자와 트레이딩은 어떻게 다른지, 그리고 퀀트 투자가 무엇인지를 처음부터 배워봅니다.

---

## 1.1 주식이란 무엇인가

### 주식의 정의

**주식(Stock)**이란 회사의 소유권을 잘게 나눈 조각입니다.

쉽게 비유하면 이렇습니다:

> 친구 5명이 각각 100만원씩 모아서 500만원으로 카페를 차렸다고 생각해보세요.
> 각 친구는 카페의 1/5(20%)를 소유한 겁니다.
> 이 "소유권 조각"이 바로 주식입니다.

실제 기업도 마찬가지입니다. 삼성전자는 약 60억 개의 주식을 발행했고, 이 주식 1개를 사면 삼성전자의 60억 분의 1을 소유하게 되는 것입니다.

### 핵심 용어 정리

| 용어 | 의미 | 실제 예시 |
|------|------|-----------|
| **주식(Stock)** | 회사 소유권의 단위 조각 | 삼성전자 보통주 1주 |
| **주가(Stock Price)** | 주식 1개의 현재 거래 가격 | 삼성전자 1주 = 약 70,000원 |
| **시가총액(Market Cap)** | 주가 × 발행 주식 수. 회사의 전체 가치를 나타냄 | 70,000원 × 60억주 = 약 420조원 |
| **거래량(Volume)** | 하루 동안 사고 팔린 주식의 수 | 오늘 삼성전자 1,000만주 거래됨 |
| **상장(IPO)** | 회사 주식을 증권거래소에 등록하여 누구나 사고팔 수 있게 하는 것 | 카카오가 2017년 코스피에 상장 |
| **배당(Dividend)** | 회사가 이익의 일부를 주주에게 나눠주는 것 | 삼성전자가 주당 1,444원 배당 |
| **호가(Bid/Ask)** | 사고 싶은 가격(매수호가)과 팔고 싶은 가격(매도호가) | 매수호가 69,900원 / 매도호가 70,000원 |
| **스프레드(Spread)** | 매수호가와 매도호가의 차이 | 70,000 - 69,900 = 100원 |
| **틱(Tick)** | 주가가 움직일 수 있는 최소 단위 | 50,000원 이상 종목은 100원 단위로 변동 |

### 주식 시장의 구조

한국의 주식 시장은 크게 두 곳으로 나뉩니다:

1. **코스피(KOSPI)**: 대형 우량 기업이 상장된 시장
   - 예: 삼성전자, SK하이닉스, 현대자동차
   - 약 800개 이상의 기업이 상장

2. **코스닥(KOSDAQ)**: 중소형, 기술 성장 기업이 상장된 시장
   - 예: 에코프로비엠, 셀트리온헬스케어
   - 약 1,600개 이상의 기업이 상장

**거래 시간**:
- 정규 거래: 오전 9:00 ~ 오후 3:30
- 시간외 거래: 오후 3:40 ~ 오후 4:00 (종가매매)
- 장 시작 전 동시호가: 오전 8:30 ~ 9:00

> 💡 **핵심 요약**
> 주식 = 회사의 소유권 조각. 주가가 오르면 내 자산이 늘고, 내리면 줄어듭니다.
> 시가총액이 클수록 대형주, 작을수록 소형주라고 부릅니다.

### 암호화폐(코인) 시장

암호화폐 시장은 주식 시장과 비슷하지만 몇 가지 차이가 있습니다:

| 구분 | 주식 시장 | 암호화폐 시장 |
|------|-----------|---------------|
| 거래 시간 | 평일 오전 9시 ~ 오후 3시 30분 | **24시간 365일** |
| 가격 변동 제한 | 상한가/하한가 ±30% | **제한 없음** |
| 거래 단위 | 1주 단위 | **소수점 단위 가능** (0.001 BTC) |
| 대표 거래소 | 한국거래소(KRX) | 업비트, 빗썸, 바이낸스 |

## 1.2 투자 vs 트레이딩 vs 퀀트 투자의 차이

주식으로 수익을 내는 방법은 여러 가지가 있습니다. 크게 3가지로 나눠보겠습니다.

### 투자 (Investing)

**"좋은 회사를 싸게 사서 오래 보유한다"**

- **시간 범위**: 수개월 ~ 수년 이상
- **핵심 분석 방법**: 기본적 분석 (재무제표, 산업 전망, 경영진 능력 등)
- **예시**: "삼성전자는 반도체 시장에서 1위이고, 매년 수십조 원의 이익을 내니까 10년 이상 보유하겠다"
- **대표 인물**: 워런 버핏 (버크셔 해서웨이)
- **장점**: 단기 시장 변동에 스트레스받지 않음, 복리 효과
- **단점**: 인내심 필요, 잘못된 기업 선택 시 장기 손실

### 트레이딩 (Trading)

**"가격 변동을 이용하여 단기에 수익을 낸다"**

- **시간 범위**: 수초 ~ 수주
- **핵심 분석 방법**: 기술적 분석 (차트, 지표, 패턴 등)
- **유형**:
  - **스캘핑**: 수초~수분 내 매매 (하루 수십~수백 번)
  - **데이트레이딩**: 당일 매수 후 당일 매도
  - **스윙트레이딩**: 수일~수주 보유 후 매도
- **장점**: 빠른 수익 가능, 하락장에서도 수익 가능
- **단점**: 높은 스트레스, 수수료 누적, 대부분의 트레이더가 손실

### 퀀트 투자 (Quantitative Investing)

**"수학적 모델과 데이터 분석으로 투자 결정을 내린다"**

이것이 바로 우리가 이 튜토리얼에서 구축할 방식입니다!

- **시간 범위**: 전략에 따라 다양 (초단위 ~ 수개월)
- **핵심 분석 방법**: 통계, 수학 모델, 프로그래밍
- **특징**:
  - 감정이 개입되지 않음 (컴퓨터가 판단)
  - 백테스팅으로 과거 데이터에서 전략 검증 가능
  - 24시간 자동 실행 가능
- **필요 기술**: 프로그래밍 (Python), 통계학 기초, 금융 지식
- **장점**: 감정 배제, 일관된 전략 실행, 동시에 여러 종목 모니터링 가능
- **단점**: 과최적화(overfitting) 위험, 시스템 오류 위험, 초기 개발 시간 투자

```
┌─────────────────────────────────────────────────────┐
│                   퀀트 투자 흐름                      │
│                                                      │
│  데이터 수집 → 전략 설계 → 백테스팅 → 자동 매매      │
│                                                      │
│  (차트/지표)   (규칙 정의)  (과거 검증)  (시스템 실행)  │
└─────────────────────────────────────────────────────┘
```

> 💡 **핵심 요약**
> - **투자**: 좋은 회사를 골라 오래 보유 (워런 버핏 스타일)
> - **트레이딩**: 차트를 보고 단기 매매 (감과 경험 기반)
> - **퀀트 투자**: 데이터와 프로그래밍으로 자동 매매 (이 튜토리얼의 목표!)

## 1.3 초보자가 반드시 알아야 할 투자 원칙 5가지

### 원칙 1: 잃지 않는 것이 가장 중요하다

> "투자의 첫 번째 규칙은 돈을 잃지 않는 것이고, 두 번째 규칙은 첫 번째 규칙을 잊지 않는 것이다." - 워런 버핏

왜 중요한가? 수학적으로 생각해보세요:

- 100만원에서 **50% 손실** → 50만원
- 50만원에서 **50% 수익** → 75만원 (원금 회복 불가!)
- 50만원에서 원금 회복하려면 → **100% 수익**이 필요

| 손실률 | 원금 회복에 필요한 수익률 |
|--------|--------------------------|
| -10% | +11.1% |
| -20% | +25.0% |
| -30% | +42.9% |
| -50% | +100.0% |
| -70% | +233.3% |
| -90% | +900.0% |

**교훈**: 손실이 커질수록 회복이 기하급수적으로 어려워집니다. 반드시 **손절매(Stop Loss)**를 설정하세요.

### 원칙 2: 분산 투자하라

> "모든 달걀을 한 바구니에 담지 마라."

- **나쁜 예**: 전 재산 1,000만원을 삼성전자 1종목에 올인
- **좋은 예**: 300만원 삼성전자 + 300만원 카카오 + 200만원 비트코인 + 200만원 현금 보유

분산 투자의 방법:
1. **종목 분산**: 여러 종목에 나눠 투자
2. **산업 분산**: 반도체, IT, 바이오 등 다양한 산업에 투자
3. **자산 분산**: 주식, 암호화폐, 현금, 채권 등 다양한 자산에 투자
4. **시간 분산**: 한 번에 다 사지 말고 나눠서 매수 (적립식 투자)

### 원칙 3: 투자 금액은 잃어도 되는 돈으로

**절대 지켜야 할 규칙**:
- 생활비, 비상금, 대출금으로 투자하지 않는다
- 전체 자산의 일정 비율만 투자에 사용한다
- 특히 자동매매 시스템은 반드시 **소액**으로 시작한다

> ⚠️ **주의**
> 자동매매 시스템에 버그가 있으면 순식간에 큰 손실이 발생할 수 있습니다.
> 반드시 모의투자로 충분히 테스트한 후, 소액부터 시작하세요.

### 원칙 4: 전략을 세우고, 전략대로 실행하라

감정에 의한 매매는 실패의 지름길입니다:

| 상황 | 감정적 반응 | 올바른 반응 |
|------|------------|------------|
| 주가가 급등할 때 | "지금 안 사면 늦어!" (FOMO) | 전략 조건을 확인하고 판단 |
| 주가가 급락할 때 | "더 떨어지기 전에 팔자!" (패닉셀) | 손절 기준에 해당하는지 확인 |
| 수익이 나고 있을 때 | "조금만 더!" (탐욕) | 목표 수익률에 도달하면 매도 |
| 손실이 나고 있을 때 | "곧 오르겠지..." (희망) | 손절 기준에 도달하면 즉시 매도 |

**이것이 바로 퀀트 투자의 핵심 장점입니다!**
프로그래밍으로 정해진 규칙을 감정 없이 실행하기 때문에 이런 실수를 방지할 수 있습니다.

### 원칙 5: 꾸준히 공부하라

투자 시장은 끊임없이 변합니다. 한번 배웠다고 끝이 아닙니다.

**추천 공부 방법**:
1. 이 튜토리얼을 처음부터 끝까지 따라하기
2. TradingView에서 매일 30분씩 차트 분석 연습
3. 모의투자로 3개월 이상 연습
4. 투자 일지 작성 (왜 샀는지, 왜 팔았는지 기록)
5. 백테스팅으로 전략 검증 → 개선 → 재검증 반복

## 1.4 이 튜토리얼에서 만들 시스템의 전체 그림

```
┌─────────────────────────────────────────────────────────────┐
│                    전체 시스템 아키텍처                        │
│                                                              │
│  ┌──────────────┐    Webhook     ┌──────────────┐            │
│  │  TradingView  │──────────────→│   FastAPI     │            │
│  │  (차트 분석)   │   매매 신호    │   (서버)      │            │
│  └──────────────┘               └──────┬───────┘            │
│                                        │                     │
│                              ┌─────────┴─────────┐          │
│                              │                    │          │
│                         ┌────▼────┐         ┌────▼────┐     │
│                         │ 업비트   │         │  KIS    │     │
│                         │ (코인)   │         │ (주식)   │     │
│                         └────┬────┘         └────┬────┘     │
│                              │                    │          │
│                              └─────────┬─────────┘          │
│                                        │                     │
│                                  ┌─────▼─────┐              │
│                                  │  Telegram  │              │
│                                  │  (알림)     │              │
│                                  └───────────┘              │
│                                                              │
│  📊 TradingView에서 조건 충족 → 🔔 Alert 발생                 │
│  → 🌐 Webhook으로 FastAPI 서버에 신호 전송                     │
│  → 🤖 서버가 자동으로 거래소에 주문                             │
│  → 📱 텔레그램으로 결과 알림                                   │
└─────────────────────────────────────────────────────────────┘
```
