# TradingView + Python 퀀트 자동매매 시스템 구축 완전 튜토리얼

> 주식 초보자부터 자동매매 시스템 구축까지, 단계별 완전 입문 가이드

---

## 대상 독자

- 주식 투자 경험이 전혀 없는 완전 초보자
- 차트, 지표, 전략 개념을 처음 접하는 분
- Python 기초 문법은 알고 있는 분
- TradingView + Python + FastAPI로 퀀트 자동매매 시스템을 만들고 싶은 분

---

## 기술 스택

| 분류 | 기술 |
|------|------|
| 언어 | Python 3.11+ |
| 웹 프레임워크 | FastAPI |
| 데이터 처리 | pandas, numpy |
| 기술적 분석 | pandas-ta |
| 암호화폐 거래소 | 업비트 Open API + pyupbit |
| 국내 주식 거래소 | 한국투자증권 KIS Developers Open API |
| 스케줄링 | APScheduler |
| 데이터베이스 | SQLite (입문) → PostgreSQL (심화) |
| ORM | SQLAlchemy |
| 환경설정 | pydantic-settings (.env 관리) |
| 알림 | python-telegram-bot |
| 서버 | Uvicorn |
| 패키지 관리 | uv 또는 pip |
