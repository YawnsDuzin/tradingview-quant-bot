## 6.1 전략 공통 규칙

### 전략 평가 기준

모든 전략은 다음 요소를 포함해야 합니다:

1. **진입 조건(Entry)**: 언제 매수/매도하는가
2. **청산 조건(Exit)**: 언제 포지션을 종료하는가
3. **손절 기준(Stop Loss)**: 손실이 얼마나 났을 때 강제 종료하는가
4. **목표 수익(Take Profit)**: 얼마의 수익이 났을 때 종료하는가
5. **적합 시장**: 어떤 시장 환경에서 효과적인가

### 백테스트 없이 실전 투입 금지!

> ⚠️ **절대 규칙**
> 10장에서 배울 **백테스팅**을 거치지 않은 전략은 절대 실전에 사용하지 마세요.
> 반드시 과거 데이터로 수익성을 검증한 후, **모의투자**로 실제 환경에서 테스트한 뒤에 실전에 적용해야 합니다.

## 6.2 전략 1: 골든크로스 / 데드크로스 전략

### 전략 개요 및 원리

**가장 고전적이고 유명한 추세 추종 전략**입니다.

단기 이동평균선이 장기 이동평균선을 돌파하는 시점을 매매 신호로 활용합니다. 추세가 명확한 시장에서 강력한 성과를 보입니다.

### 사용 지표

- **단기 이동평균선**: SMA(5) 또는 SMA(20)
- **장기 이동평균선**: SMA(20) 또는 SMA(60)

### 매수/매도 조건

| 조건 | 의미 |
|------|------|
| **매수(Buy)** | 단기선이 장기선을 **아래에서 위로** 돌파 (골든크로스) |
| **매도(Sell)** | 단기선이 장기선을 **위에서 아래로** 돌파 (데드크로스) |

### 손절 기준

- 진입가 대비 **-5% ~ -7%** 하락 시 손절
- 또는 단기선이 다시 장기선 아래로 내려가면 손절

### 적합한 시장 환경

- **강한 추세가 있는 시장** (상승장 또는 하락장)
- **주봉/일봉 차트**에서 효과적
- **횡보장에서는 잦은 신호로 인해 손실 가능** → 부적합

### TradingView에서 설정하기

1. 차트에 **SMA(5)**와 **SMA(20)** 두 개 추가
2. 색상을 다르게 설정하여 구분 (예: 5일선 빨강, 20일선 파랑)
3. 두 선이 교차하는 지점을 매매 신호로 관찰

### 💻 Python 구현 코드

```python
"""
골든크로스/데드크로스 전략
"""
from __future__ import annotations

from typing import Literal

import pandas as pd
import pandas_ta as ta


Signal = Literal["BUY", "SELL", "HOLD"]


def golden_cross_strategy(
    df: pd.DataFrame,
    short_period: int = 5,
    long_period: int = 20,
) -> pd.DataFrame:
    """
    골든크로스/데드크로스 전략 신호 생성

    Args:
        df: OHLCV DataFrame (close 컬럼 필수)
        short_period: 단기 이동평균 기간
        long_period: 장기 이동평균 기간

    Returns:
        signal 컬럼이 추가된 DataFrame
        - "BUY": 골든크로스 발생
        - "SELL": 데드크로스 발생
        - "HOLD": 유지
    """
    df = df.copy()
    df[f"SMA_{short_period}"] = ta.sma(df["close"], length=short_period)
    df[f"SMA_{long_period}"] = ta.sma(df["close"], length=long_period)

    # 이전 값과 현재 값의 차이로 교차 감지
    prev_diff = df[f"SMA_{short_period}"].shift(1) - df[f"SMA_{long_period}"].shift(1)
    curr_diff = df[f"SMA_{short_period}"] - df[f"SMA_{long_period}"]

    signals: list[Signal] = []
    for prev, curr in zip(prev_diff, curr_diff):
        if pd.isna(prev) or pd.isna(curr):
            signals.append("HOLD")
        elif prev < 0 and curr > 0:
            # 골든크로스: 단기선이 장기선을 상향 돌파
            signals.append("BUY")
        elif prev > 0 and curr < 0:
            # 데드크로스: 단기선이 장기선을 하향 돌파
            signals.append("SELL")
        else:
            signals.append("HOLD")

    df["signal"] = signals
    return df


def check_stop_loss(
    entry_price: float,
    current_price: float,
    stop_loss_pct: float = 0.05,
) -> bool:
    """
    손절 조건 확인

    Args:
        entry_price: 진입 가격
        current_price: 현재 가격
        stop_loss_pct: 손절 비율 (0.05 = 5%)

    Returns:
        손절 필요 여부
    """
    loss_pct = (entry_price - current_price) / entry_price
    return loss_pct >= stop_loss_pct


if __name__ == "__main__":
    import pyupbit

    # 비트코인 일봉 200개 데이터
    df: pd.DataFrame = pyupbit.get_ohlcv("KRW-BTC", interval="day", count=200)
    result = golden_cross_strategy(df, short_period=5, long_period=20)

    # 최근 신호 출력
    recent_signals = result[result["signal"] != "HOLD"].tail(10)
    print("최근 매매 신호 10건:")
    print(recent_signals[["close", "SMA_5", "SMA_20", "signal"]])
```

> 💡 **실전 팁**
> 1. 단독 사용 시 승률이 낮을 수 있음 → **추세 필터** 추가 (200일선 위에서만 매수)
> 2. **거래량 확인**: 골든크로스 시 거래량이 증가하면 신뢰도 상승
> 3. **여러 시간프레임** 확인: 일봉 골든크로스 + 주봉 상승추세

## 6.3 전략 2: RSI + 볼린저 밴드 조합 전략

### 전략 개요 및 원리

**역추세(Mean Reversion) 전략**으로, 과매수/과매도 상태에서 평균으로 회귀하는 경향을 이용합니다.

RSI로 과매도를 확인하고 볼린저 밴드 하단 터치로 매수, RSI 과매수와 볼린저 밴드 상단 터치로 매도합니다.

### 사용 지표

- **RSI(14)**: 과매수/과매도 판단
- **볼린저 밴드(20, 2)**: 가격의 상대적 위치 판단

### 매수/매도 조건

| 조건 | 설명 |
|------|------|
| **매수(Buy)** | RSI < 30 **AND** 종가 < 볼린저 하단 |
| **매도(Sell)** | RSI > 70 **AND** 종가 > 볼린저 상단 |

### 손절 기준

- 진입가 대비 **-3% ~ -5%** (역추세 전략은 빠른 손절 필요)
- 또는 RSI가 정상 범위(30~70)로 돌아왔는데 가격이 계속 역방향이면 손절

### 목표 수익

- 볼린저 밴드 **중앙선(SMA 20)**까지 도달하면 청산
- 또는 RSI 50 도달 시 청산

### 적합한 시장 환경

- **횡보장(Ranging Market)** → 가장 효과적
- **강한 추세장**에서는 부적합 (가격이 밴드 워킹할 수 있음)

### TradingView에서 설정하기

1. 차트에 **Bollinger Bands** 추가 (기본값: 20, 2)
2. 차트에 **RSI** 추가 (기본값: 14)
3. RSI 지표에 30, 70 수평선 표시
4. 매수/매도 조건 동시 발생 시점 관찰

### 💻 Python 구현 코드

```python
"""
RSI + 볼린저 밴드 조합 전략
"""
from __future__ import annotations

from typing import Literal

import pandas as pd
import pandas_ta as ta


Signal = Literal["BUY", "SELL", "HOLD"]


def rsi_bollinger_strategy(
    df: pd.DataFrame,
    rsi_length: int = 14,
    rsi_oversold: float = 30,
    rsi_overbought: float = 70,
    bb_length: int = 20,
    bb_std: float = 2.0,
) -> pd.DataFrame:
    """
    RSI + 볼린저 밴드 조합 전략

    Args:
        df: OHLCV DataFrame
        rsi_length: RSI 기간
        rsi_oversold: RSI 과매도 임계값
        rsi_overbought: RSI 과매수 임계값
        bb_length: 볼린저 밴드 기간
        bb_std: 볼린저 밴드 표준편차

    Returns:
        signal 컬럼이 추가된 DataFrame
    """
    df = df.copy()

    # RSI 계산
    df["RSI"] = ta.rsi(df["close"], length=rsi_length)

    # 볼린저 밴드 계산
    bb = ta.bbands(df["close"], length=bb_length, std=bb_std)
    df["BB_lower"] = bb[f"BBL_{bb_length}_{bb_std}"]
    df["BB_middle"] = bb[f"BBM_{bb_length}_{bb_std}"]
    df["BB_upper"] = bb[f"BBU_{bb_length}_{bb_std}"]

    signals: list[Signal] = []
    for i in range(len(df)):
        rsi_val = df["RSI"].iloc[i]
        close = df["close"].iloc[i]
        bb_lower = df["BB_lower"].iloc[i]
        bb_upper = df["BB_upper"].iloc[i]

        if pd.isna(rsi_val) or pd.isna(bb_lower):
            signals.append("HOLD")
            continue

        # 매수: RSI 과매도 + 종가가 볼린저 하단 아래
        if rsi_val < rsi_oversold and close < bb_lower:
            signals.append("BUY")
        # 매도: RSI 과매수 + 종가가 볼린저 상단 위
        elif rsi_val > rsi_overbought and close > bb_upper:
            signals.append("SELL")
        else:
            signals.append("HOLD")

    df["signal"] = signals
    return df


if __name__ == "__main__":
    import pyupbit

    df = pyupbit.get_ohlcv("KRW-BTC", interval="day", count=200)
    result = rsi_bollinger_strategy(df)

    recent = result[result["signal"] != "HOLD"].tail(10)
    print("최근 매매 신호 10건:")
    print(recent[["close", "RSI", "BB_lower", "BB_upper", "signal"]])
```

> 💡 **실전 팁**
> 1. 횡보장에서만 사용 (ADX < 25 필터 추가 추천)
> 2. 손절을 빠르게 설정 (역추세 전략의 특성)
> 3. 볼린저 중앙선 도달 시 일부 익절, 반대편 밴드 도달 시 전량 익절

## 6.4 전략 3: MACD + 거래량 확인 전략

### 전략 개요 및 원리

**MACD의 신호에 거래량 확인을 추가**하여 가짜 신호를 걸러내는 전략입니다.

MACD 골든크로스만으로 매수하면 속임수 신호가 많지만, 거래량이 증가한 상태에서의 골든크로스는 신뢰도가 훨씬 높습니다.

### 사용 지표

- **MACD(12, 26, 9)**: 추세 모멘텀
- **거래량 이동평균**: 거래량의 급증 여부 판단

### 매수/매도 조건

| 조건 | 설명 |
|------|------|
| **매수(Buy)** | MACD 골든크로스 **AND** 거래량 > 거래량 20일 평균 × 1.5 |
| **매도(Sell)** | MACD 데드크로스 **AND** 거래량 > 거래량 20일 평균 × 1.5 |

### 손절 기준

- 진입가 대비 **-5%** 손실 시 손절
- 또는 MACD가 반대 교차하면 손절

### 적합한 시장 환경

- **중기 추세 전환 국면**
- **거래량이 활발한 종목** (소형주/저거래량 코인은 부적합)

### 💻 Python 구현 코드

```python
"""
MACD + 거래량 확인 전략
"""
from __future__ import annotations

from typing import Literal

import pandas as pd
import pandas_ta as ta


Signal = Literal["BUY", "SELL", "HOLD"]


def macd_volume_strategy(
    df: pd.DataFrame,
    macd_fast: int = 12,
    macd_slow: int = 26,
    macd_signal: int = 9,
    volume_ma_length: int = 20,
    volume_multiplier: float = 1.5,
) -> pd.DataFrame:
    """
    MACD + 거래량 확인 전략

    Args:
        df: OHLCV DataFrame
        macd_fast: MACD 빠른 EMA 기간
        macd_slow: MACD 느린 EMA 기간
        macd_signal: MACD 시그널 기간
        volume_ma_length: 거래량 이동평균 기간
        volume_multiplier: 거래량 배수 (1.5 = 평균의 150%)

    Returns:
        signal 컬럼이 추가된 DataFrame
    """
    df = df.copy()

    # MACD 계산
    macd = ta.macd(df["close"], fast=macd_fast, slow=macd_slow, signal=macd_signal)
    df["MACD"] = macd[f"MACD_{macd_fast}_{macd_slow}_{macd_signal}"]
    df["MACD_signal"] = macd[f"MACDs_{macd_fast}_{macd_slow}_{macd_signal}"]
    df["MACD_hist"] = macd[f"MACDh_{macd_fast}_{macd_slow}_{macd_signal}"]

    # 거래량 이동평균
    df["volume_ma"] = ta.sma(df["volume"], length=volume_ma_length)

    # 이전/현재 MACD - Signal 차이
    prev_diff = df["MACD"].shift(1) - df["MACD_signal"].shift(1)
    curr_diff = df["MACD"] - df["MACD_signal"]

    signals: list[Signal] = []
    for i in range(len(df)):
        if pd.isna(prev_diff.iloc[i]) or pd.isna(df["volume_ma"].iloc[i]):
            signals.append("HOLD")
            continue

        volume_surge = df["volume"].iloc[i] > df["volume_ma"].iloc[i] * volume_multiplier

        # 매수: MACD 골든크로스 + 거래량 급증
        if prev_diff.iloc[i] < 0 and curr_diff.iloc[i] > 0 and volume_surge:
            signals.append("BUY")
        # 매도: MACD 데드크로스 + 거래량 급증
        elif prev_diff.iloc[i] > 0 and curr_diff.iloc[i] < 0 and volume_surge:
            signals.append("SELL")
        else:
            signals.append("HOLD")

    df["signal"] = signals
    return df


if __name__ == "__main__":
    import pyupbit

    df = pyupbit.get_ohlcv("KRW-BTC", interval="day", count=200)
    result = macd_volume_strategy(df)

    recent = result[result["signal"] != "HOLD"].tail(10)
    print("최근 매매 신호 10건:")
    print(recent[["close", "MACD", "MACD_signal", "volume", "volume_ma", "signal"]])
```

> 💡 **실전 팁**
> 1. 거래량 배수는 종목 특성에 따라 조정 (1.5~3배)
> 2. MACD 히스토그램이 확장 중일 때 신호 신뢰도 상승
> 3. 0선 위에서 골든크로스는 매우 강력한 매수 신호

## 6.5 전략 4: 지지/저항 돌파 전략 (Breakout)

### 전략 개요 및 원리

**박스권(횡보장)에서 가격이 저항선을 돌파할 때 매수**, **지지선을 이탈할 때 매도**하는 전략입니다.

돌파(Breakout) 전략은 큰 움직임의 시작을 잡을 수 있어 수익률이 크지만, 가짜 돌파(Fake Breakout)도 많아 리스크 관리가 중요합니다.

### 사용 지표

- **N일 최고가/최저가**: Donchian Channel 방식
- **거래량**: 돌파 시 거래량 증가 확인

### 매수/매도 조건

| 조건 | 설명 |
|------|------|
| **매수(Buy)** | 종가 > 최근 20일 최고가 **AND** 거래량 증가 |
| **매도(Sell)** | 종가 < 최근 20일 최저가 **AND** 거래량 증가 |

### 손절 기준

- 진입가 대비 **-3% ~ -5%**
- 또는 돌파한 지지/저항선 다시 이탈 시 (가짜 돌파 방지)

### 목표 수익

- **ATR 기반** (Average True Range × 2)
- 또는 고정 비율 (10~20%)

### 적합한 시장 환경

- **박스권 이후의 추세 발생**
- **거래량이 충분한 종목**

### 💻 Python 구현 코드

```python
"""
지지/저항 돌파 전략 (Donchian Channel Breakout)
"""
from __future__ import annotations

from typing import Literal

import pandas as pd
import pandas_ta as ta


Signal = Literal["BUY", "SELL", "HOLD"]


def breakout_strategy(
    df: pd.DataFrame,
    lookback: int = 20,
    volume_confirmation: bool = True,
    volume_multiplier: float = 1.2,
) -> pd.DataFrame:
    """
    돌파 전략 (Donchian Channel 기반)

    Args:
        df: OHLCV DataFrame
        lookback: 최고가/최저가 조회 기간
        volume_confirmation: 거래량 확인 여부
        volume_multiplier: 거래량 배수

    Returns:
        signal 컬럼이 추가된 DataFrame
    """
    df = df.copy()

    # 최근 N일 최고가/최저가 (오늘 제외)
    df["highest"] = df["high"].rolling(window=lookback).max().shift(1)
    df["lowest"] = df["low"].rolling(window=lookback).min().shift(1)

    # 거래량 평균
    df["volume_ma"] = ta.sma(df["volume"], length=lookback)

    signals: list[Signal] = []
    for i in range(len(df)):
        close = df["close"].iloc[i]
        highest = df["highest"].iloc[i]
        lowest = df["lowest"].iloc[i]
        volume = df["volume"].iloc[i]
        volume_ma = df["volume_ma"].iloc[i]

        if pd.isna(highest) or pd.isna(lowest) or pd.isna(volume_ma):
            signals.append("HOLD")
            continue

        volume_ok = not volume_confirmation or (volume > volume_ma * volume_multiplier)

        # 매수: 종가가 최근 N일 최고가 돌파
        if close > highest and volume_ok:
            signals.append("BUY")
        # 매도: 종가가 최근 N일 최저가 이탈
        elif close < lowest and volume_ok:
            signals.append("SELL")
        else:
            signals.append("HOLD")

    df["signal"] = signals
    return df


def calculate_atr_stop(
    df: pd.DataFrame,
    entry_price: float,
    atr_length: int = 14,
    atr_multiplier: float = 2.0,
) -> float:
    """
    ATR 기반 손절가 계산

    Args:
        df: OHLCV DataFrame
        entry_price: 진입 가격
        atr_length: ATR 기간
        atr_multiplier: ATR 배수

    Returns:
        손절 가격
    """
    atr = ta.atr(df["high"], df["low"], df["close"], length=atr_length)
    latest_atr = float(atr.iloc[-1])
    return entry_price - (latest_atr * atr_multiplier)


if __name__ == "__main__":
    import pyupbit

    df = pyupbit.get_ohlcv("KRW-BTC", interval="day", count=200)
    result = breakout_strategy(df, lookback=20)

    recent = result[result["signal"] != "HOLD"].tail(10)
    print("최근 돌파 신호 10건:")
    print(recent[["close", "highest", "lowest", "signal"]])
```

> 💡 **실전 팁**
> 1. **가짜 돌파 방지**: 돌파 후 종가가 유지되는지 1~2일 확인
> 2. **거래량 필터 필수**: 거래량 없는 돌파는 무시
> 3. **ATR 기반 손절**: 변동성에 맞춰 손절폭 자동 조정

## 6.6 전략 5: 추세 추종 전략 (Trend Following)

### 전략 개요 및 원리

**"추세에 올라타서 끝까지 간다"** - 가장 단순하면서도 장기적으로 가장 효과적인 전략 중 하나입니다.

거북이 트레이더(Turtle Traders)로 유명한 전략으로, 복수의 이동평균선과 ADX(추세 강도 지표)를 조합합니다.

### 사용 지표

- **EMA(20), EMA(50), EMA(200)**: 추세 방향
- **ADX(14)**: 추세의 강도
- **ATR(14)**: 변동성 기반 손절

### 매수/매도 조건

| 조건 | 설명 |
|------|------|
| **매수(Buy)** | 종가 > EMA(20) > EMA(50) > EMA(200) **AND** ADX > 25 |
| **청산(Exit)** | 종가 < EMA(20) **OR** ADX < 20 |

### 손절 기준

- **ATR × 2** 기반 동적 손절
- 또는 EMA(50) 하향 이탈 시

### 적합한 시장 환경

- **강한 상승 추세** (불장)
- 월봉/주봉 차트에서 장기 투자

### TradingView에서 설정하기

1. **EMA(20), EMA(50), EMA(200)** 세 개 추가
2. **ADX** 지표 추가
3. 정배열(20 > 50 > 200) + ADX 25 이상 조건에서 관찰

### 💻 Python 구현 코드

```python
"""
추세 추종 전략
"""
from __future__ import annotations

from typing import Literal

import pandas as pd
import pandas_ta as ta


Signal = Literal["BUY", "SELL", "HOLD"]


def trend_following_strategy(
    df: pd.DataFrame,
    ema_short: int = 20,
    ema_mid: int = 50,
    ema_long: int = 200,
    adx_threshold: float = 25.0,
    adx_exit_threshold: float = 20.0,
) -> pd.DataFrame:
    """
    추세 추종 전략 (EMA 정배열 + ADX 필터)

    Args:
        df: OHLCV DataFrame
        ema_short: 단기 EMA 기간
        ema_mid: 중기 EMA 기간
        ema_long: 장기 EMA 기간
        adx_threshold: 매수 시 ADX 기준
        adx_exit_threshold: 청산 시 ADX 기준

    Returns:
        signal 컬럼이 추가된 DataFrame
    """
    df = df.copy()

    # EMA 계산
    df[f"EMA_{ema_short}"] = ta.ema(df["close"], length=ema_short)
    df[f"EMA_{ema_mid}"] = ta.ema(df["close"], length=ema_mid)
    df[f"EMA_{ema_long}"] = ta.ema(df["close"], length=ema_long)

    # ADX 계산 (추세 강도)
    adx_df = ta.adx(df["high"], df["low"], df["close"], length=14)
    df["ADX"] = adx_df["ADX_14"]

    signals: list[Signal] = []
    for i in range(len(df)):
        close = df["close"].iloc[i]
        ema_s = df[f"EMA_{ema_short}"].iloc[i]
        ema_m = df[f"EMA_{ema_mid}"].iloc[i]
        ema_l = df[f"EMA_{ema_long}"].iloc[i]
        adx = df["ADX"].iloc[i]

        if any(pd.isna(v) for v in [ema_s, ema_m, ema_l, adx]):
            signals.append("HOLD")
            continue

        # 매수: 정배열 + 강한 추세
        if close > ema_s > ema_m > ema_l and adx > adx_threshold:
            signals.append("BUY")
        # 청산: EMA 단기선 이탈 또는 추세 약화
        elif close < ema_s or adx < adx_exit_threshold:
            signals.append("SELL")
        else:
            signals.append("HOLD")

    df["signal"] = signals
    return df


if __name__ == "__main__":
    import pyupbit

    df = pyupbit.get_ohlcv("KRW-BTC", interval="day", count=300)
    result = trend_following_strategy(df)

    recent = result.tail(30)
    buy_signals = recent[recent["signal"] == "BUY"]
    print(f"최근 30일 중 매수 신호 발생: {len(buy_signals)}회")
    print(recent[["close", "EMA_20", "EMA_50", "EMA_200", "ADX", "signal"]].tail(10))
```

> 💡 **실전 팁**
> 1. **수익 극대화**: 정배열이 유지되는 동안 포지션 유지 (익절 서두르지 말기)
> 2. **Trailing Stop**: 고점 대비 일정 비율 하락 시 청산 (상승을 최대한 따라감)
> 3. **긴 시간프레임**: 일봉 이상에서 사용 (단기 노이즈 회피)

## 6.7 전략 통합 비교표

| 전략 | 유형 | 적합 시장 | 승률 | 손익비 | 난이도 |
|------|------|-----------|------|--------|--------|
| 골든크로스 | 추세 추종 | 추세장 | 낮음 | 높음 | ★☆☆☆☆ |
| RSI+BB | 역추세 | 횡보장 | 높음 | 낮음 | ★★☆☆☆ |
| MACD+거래량 | 추세 전환 | 중기 추세 | 중간 | 중간 | ★★★☆☆ |
| 돌파 | 추세 추종 | 박스권 이후 | 낮음 | 매우 높음 | ★★★☆☆ |
| 추세 추종 | 추세 추종 | 강한 상승장 | 중간 | 매우 높음 | ★★★★☆ |

### 어떤 전략을 선택해야 할까?

- **초보자**: 골든크로스 → 단순하고 이해하기 쉬움
- **횡보장 수익 추구**: RSI + 볼린저 밴드
- **큰 움직임 포착**: 돌파 전략 또는 추세 추종
- **리스크 분산**: 여러 전략을 조합하여 운용

> ⚠️ **절대 원칙**
> 어떤 전략을 선택하든 반드시 **백테스팅 → 모의투자 → 소액 실전 → 점진적 확대** 단계를 거치세요.
