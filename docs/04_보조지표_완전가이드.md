# 4장. 보조지표(Indicator) 완전 가이드

> 지표는 가격 데이터에 수학적 계산을 적용하여 시장의 상태를 파악하는 도구입니다.
> 이 장에서는 가장 중요한 지표들을 하나씩 배우고, Python으로 직접 계산해봅니다.

## 4.1 지표란 무엇인가, 왜 사용하는가

### 지표의 정의

**보조지표(Technical Indicator)**는 가격과 거래량 데이터에 수학 공식을 적용하여 만든 숫자나 그래프입니다.

쉽게 비유하면:
> 차트가 "환자의 X-ray 사진"이라면,
> 지표는 "혈압계, 체온계, 심전도"처럼 다양한 각도에서 상태를 측정하는 도구입니다.

### 왜 지표를 사용하는가?

1. **객관적 판단**: 주관적 느낌이 아닌 수치로 판단
2. **노이즈 제거**: 복잡한 가격 움직임을 단순화
3. **자동화 가능**: 수치 기반이므로 프로그램으로 매매 가능
4. **다양한 관점**: 추세, 모멘텀, 거래량 등 여러 각도에서 분석

### 지표의 3가지 분류

| 분류 | 측정 대상 | 대표 지표 |
|------|-----------|-----------|
| **추세 지표** | 가격이 어느 방향으로 가는가 | MA, EMA, MACD, 볼린저밴드 |
| **모멘텀 지표** | 추세의 강도/속도 | RSI, 스토캐스틱, CCI |
| **거래량 지표** | 매매 세력의 크기 | OBV, 볼륨 프로파일 |

> ⚠️ **주의**
> 어떤 지표도 100% 정확하지 않습니다.
> 지표는 **참고 도구**일 뿐이며, 여러 지표를 함께 사용해야 신뢰도가 올라갑니다.

## 4.2 추세 지표 1: 이동평균선 (MA, EMA)

### 단순이동평균선 (SMA, Simple Moving Average)

**정의**: 최근 N일간의 **종가 평균**을 이어 그린 선

**계산 공식**:
```
SMA(N) = (P1 + P2 + P3 + ... + PN) ÷ N
```
- P: 종가
- N: 기간 (예: 5일, 20일, 60일)

**실제 숫자 예시**: 5일 이동평균선 계산

| 날짜 | 종가 | 5일 SMA 계산 | SMA 값 |
|------|------|--------------|--------|
| 1/8 | 70,000 | - | - |
| 1/9 | 71,000 | - | - |
| 1/10 | 72,000 | - | - |
| 1/11 | 71,500 | - | - |
| 1/12 | 73,000 | (70,000+71,000+72,000+71,500+73,000)÷5 | **71,500** |
| 1/15 | 74,000 | (71,000+72,000+71,500+73,000+74,000)÷5 | **72,300** |
| 1/16 | 73,500 | (72,000+71,500+73,000+74,000+73,500)÷5 | **72,800** |

### 지수이동평균선 (EMA, Exponential Moving Average)

**정의**: **최근 가격에 더 큰 가중치**를 주는 이동평균선

**왜 EMA가 필요한가?**
SMA는 모든 날짜에 동일한 가중치를 주지만, 현실에서는 최근 가격이 더 중요합니다. EMA는 오늘 가격에 더 큰 가중치를 주어 추세 변화에 더 빠르게 반응합니다.

**계산 공식**:
```
α = 2 ÷ (N + 1)
EMA_오늘 = (오늘 종가 × α) + (EMA_어제 × (1 - α))
```
- α(알파): 가중치 계수
- N: 기간

**실제 숫자 예시**: 5일 EMA 계산
- α = 2 ÷ (5 + 1) = 0.333

| 날짜 | 종가 | EMA 계산 | EMA 값 |
|------|------|----------|--------|
| 1/12 | 73,000 | 초기값 = SMA = 71,500 | **71,500** |
| 1/15 | 74,000 | (74,000 × 0.333) + (71,500 × 0.667) | **72,332** |
| 1/16 | 73,500 | (73,500 × 0.333) + (72,332 × 0.667) | **72,721** |

### 골든크로스와 데드크로스

**골든크로스(Golden Cross)**: 단기 이동평균선이 장기 이동평균선을 **아래에서 위로** 돌파
- 예: 5일선이 20일선을 상향 돌파
- **의미**: 상승 추세 전환 가능성 → **매수 신호**

**데드크로스(Dead Cross)**: 단기 이동평균선이 장기 이동평균선을 **위에서 아래로** 돌파
- 예: 5일선이 20일선을 하향 돌파
- **의미**: 하락 추세 전환 가능성 → **매도 신호**

```
    가격
     │
     │       단기선(5일)
     │         ╱╲
     │        ╱  ╲      ← 데드크로스
     │       ╱    ╲╱
     │──────╳──────╲────  장기선(20일)
     │     ╱        ╲
     │    ╱          ╲
     │   ╱            ╲
     │  ╱  ← 골든크로스
     │ ╱
     └────────────────→ 시간
```

### 이동평균선 활용법

| 이동평균선 | 활용 |
|------------|------|
| 5일선 | 단기 추세 (주간 방향) |
| 20일선 | 중기 추세 (월간 방향), **지지/저항 역할** |
| 60일선 | 분기 추세, 중기 지지선 |
| 120일선 | 반기 추세 |
| 200일선 | 장기 추세, **상승/하락장 구분선** |

> 💡 **실전 활용 팁**
> 1. **정배열**: 단기 > 중기 > 장기 순서 = 강한 상승 추세
> 2. **역배열**: 장기 > 중기 > 단기 순서 = 강한 하락 추세
> 3. **주가 > 200일선**: 장기 상승장, **주가 < 200일선**: 장기 하락장

### TradingView에서 이동평균선 추가하기

1. 상단 메뉴에서 **"지표(Indicators)"** 버튼 클릭
2. 검색창에 **"Moving Average"** 또는 **"이동평균"** 입력
3. **"Moving Average"** (SMA) 또는 **"Moving Average Exponential"** (EMA) 선택
4. 설정 창에서 기간(Length) 설정 (기본 9 → 원하는 값으로 변경)
5. 여러 개 추가하려면 같은 과정 반복 (5일, 20일, 60일 등)
