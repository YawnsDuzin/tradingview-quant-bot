# 4장. 보조지표(Indicator) 완전 가이드

> 지표는 가격 데이터에 수학적 계산을 적용하여 시장의 상태를 파악하는 도구입니다.
> 이 장에서는 가장 중요한 지표들을 하나씩 배우고, Python으로 직접 계산해봅니다.

## 4.1 지표란 무엇인가, 왜 사용하는가

### 지표의 정의

**보조지표(Technical Indicator)**는 가격과 거래량 데이터에 수학 공식을 적용하여 만든 숫자나 그래프입니다.

쉽게 비유하면:
> 차트가 "환자의 X-ray 사진"이라면,
> 지표는 "혈압계, 체온계, 심전도"처럼 다양한 각도에서 상태를 측정하는 도구입니다.

### 왜 지표를 사용하는가?

1. **객관적 판단**: 주관적 느낌이 아닌 수치로 판단
2. **노이즈 제거**: 복잡한 가격 움직임을 단순화
3. **자동화 가능**: 수치 기반이므로 프로그램으로 매매 가능
4. **다양한 관점**: 추세, 모멘텀, 거래량 등 여러 각도에서 분석

### 지표의 3가지 분류

| 분류 | 측정 대상 | 대표 지표 |
|------|-----------|-----------|
| **추세 지표** | 가격이 어느 방향으로 가는가 | MA, EMA, MACD, 볼린저밴드 |
| **모멘텀 지표** | 추세의 강도/속도 | RSI, 스토캐스틱, CCI |
| **거래량 지표** | 매매 세력의 크기 | OBV, 볼륨 프로파일 |

> ⚠️ **주의**
> 어떤 지표도 100% 정확하지 않습니다.
> 지표는 **참고 도구**일 뿐이며, 여러 지표를 함께 사용해야 신뢰도가 올라갑니다.

## 4.2 추세 지표 1: 이동평균선 (MA, EMA)

### 단순이동평균선 (SMA, Simple Moving Average)

**정의**: 최근 N일간의 **종가 평균**을 이어 그린 선

**계산 공식**:
```
SMA(N) = (P1 + P2 + P3 + ... + PN) ÷ N
```
- P: 종가
- N: 기간 (예: 5일, 20일, 60일)

**실제 숫자 예시**: 5일 이동평균선 계산

| 날짜 | 종가 | 5일 SMA 계산 | SMA 값 |
|------|------|--------------|--------|
| 1/8 | 70,000 | - | - |
| 1/9 | 71,000 | - | - |
| 1/10 | 72,000 | - | - |
| 1/11 | 71,500 | - | - |
| 1/12 | 73,000 | (70,000+71,000+72,000+71,500+73,000)÷5 | **71,500** |
| 1/15 | 74,000 | (71,000+72,000+71,500+73,000+74,000)÷5 | **72,300** |
| 1/16 | 73,500 | (72,000+71,500+73,000+74,000+73,500)÷5 | **72,800** |

### 지수이동평균선 (EMA, Exponential Moving Average)

**정의**: **최근 가격에 더 큰 가중치**를 주는 이동평균선

**왜 EMA가 필요한가?**
SMA는 모든 날짜에 동일한 가중치를 주지만, 현실에서는 최근 가격이 더 중요합니다. EMA는 오늘 가격에 더 큰 가중치를 주어 추세 변화에 더 빠르게 반응합니다.

**계산 공식**:
```
α = 2 ÷ (N + 1)
EMA_오늘 = (오늘 종가 × α) + (EMA_어제 × (1 - α))
```
- α(알파): 가중치 계수
- N: 기간

**실제 숫자 예시**: 5일 EMA 계산
- α = 2 ÷ (5 + 1) = 0.333

| 날짜 | 종가 | EMA 계산 | EMA 값 |
|------|------|----------|--------|
| 1/12 | 73,000 | 초기값 = SMA = 71,500 | **71,500** |
| 1/15 | 74,000 | (74,000 × 0.333) + (71,500 × 0.667) | **72,332** |
| 1/16 | 73,500 | (73,500 × 0.333) + (72,332 × 0.667) | **72,721** |

### 골든크로스와 데드크로스

**골든크로스(Golden Cross)**: 단기 이동평균선이 장기 이동평균선을 **아래에서 위로** 돌파
- 예: 5일선이 20일선을 상향 돌파
- **의미**: 상승 추세 전환 가능성 → **매수 신호**

**데드크로스(Dead Cross)**: 단기 이동평균선이 장기 이동평균선을 **위에서 아래로** 돌파
- 예: 5일선이 20일선을 하향 돌파
- **의미**: 하락 추세 전환 가능성 → **매도 신호**

```
    가격
     │
     │       단기선(5일)
     │         ╱╲
     │        ╱  ╲      ← 데드크로스
     │       ╱    ╲╱
     │──────╳──────╲────  장기선(20일)
     │     ╱        ╲
     │    ╱          ╲
     │   ╱            ╲
     │  ╱  ← 골든크로스
     │ ╱
     └────────────────→ 시간
```

### 이동평균선 활용법

| 이동평균선 | 활용 |
|------------|------|
| 5일선 | 단기 추세 (주간 방향) |
| 20일선 | 중기 추세 (월간 방향), **지지/저항 역할** |
| 60일선 | 분기 추세, 중기 지지선 |
| 120일선 | 반기 추세 |
| 200일선 | 장기 추세, **상승/하락장 구분선** |

> 💡 **실전 활용 팁**
> 1. **정배열**: 단기 > 중기 > 장기 순서 = 강한 상승 추세
> 2. **역배열**: 장기 > 중기 > 단기 순서 = 강한 하락 추세
> 3. **주가 > 200일선**: 장기 상승장, **주가 < 200일선**: 장기 하락장

### TradingView에서 이동평균선 추가하기

1. 상단 메뉴에서 **"지표(Indicators)"** 버튼 클릭
2. 검색창에 **"Moving Average"** 또는 **"이동평균"** 입력
3. **"Moving Average"** (SMA) 또는 **"Moving Average Exponential"** (EMA) 선택
4. 설정 창에서 기간(Length) 설정 (기본 9 → 원하는 값으로 변경)
5. 여러 개 추가하려면 같은 과정 반복 (5일, 20일, 60일 등)

## 4.3 추세 지표 2: MACD

### MACD란?

**MACD(Moving Average Convergence Divergence, 이동평균 수렴·발산)**는 두 개의 지수이동평균선 차이를 이용하여 추세의 방향과 강도를 파악하는 지표입니다.

### 계산 공식

```
MACD Line = EMA(12) - EMA(26)
Signal Line = EMA(9) of MACD Line
Histogram = MACD Line - Signal Line
```

**구성 요소**:
1. **MACD Line(MACD선)**: 단기(12일) EMA - 장기(26일) EMA
2. **Signal Line(시그널선)**: MACD선의 9일 EMA
3. **Histogram(히스토그램)**: MACD선과 시그널선의 차이를 막대로 표현

### 실제 숫자 예시

가정: 12일 EMA = 72,500원, 26일 EMA = 71,800원

- MACD Line = 72,500 - 71,800 = **+700**
- (MACD 값이 양수 → 단기 평균이 장기 평균보다 높음 → 상승 추세)
- (MACD 값이 음수 → 단기 평균이 장기 평균보다 낮음 → 하락 추세)

### MACD 해석 방법

| 상황 | 의미 | 매매 신호 |
|------|------|-----------|
| MACD > Signal (상향 돌파) | 단기 상승 모멘텀 강화 | **매수 신호** |
| MACD < Signal (하향 돌파) | 단기 하락 모멘텀 강화 | **매도 신호** |
| MACD > 0 | 전반적 상승 추세 | 매수 우위 |
| MACD < 0 | 전반적 하락 추세 | 매도 우위 |
| Histogram 확대 | 추세가 강해짐 | 추세 지속 |
| Histogram 축소 | 추세가 약해짐 | 전환 가능성 |

### MACD 다이버전스

**다이버전스(Divergence)**: 가격과 지표가 반대 방향으로 움직이는 현상

- **상승 다이버전스**: 가격은 **신저가**를 갱신하지만, MACD는 **더 높은 저점** → 하락 세력 약화 → **매수 신호**
- **하락 다이버전스**: 가격은 **신고가**를 갱신하지만, MACD는 **더 낮은 고점** → 상승 세력 약화 → **매도 신호**

> 💡 **실전 활용 팁**
> 1. MACD가 0선 위에서 골든크로스 → 매우 강력한 매수 신호
> 2. MACD가 0선 아래에서 데드크로스 → 매우 강력한 매도 신호
> 3. 다이버전스는 단독 사용보다는 다른 지표와 함께 확인해야 신뢰도 높음

### TradingView에서 MACD 추가하기

1. 상단 **"지표"** 버튼 클릭
2. 검색창에 **"MACD"** 입력
3. **"MACD"** 선택
4. 설정: 빠른 기간=12, 느린 기간=26, 시그널=9 (기본값 유지 추천)

## 4.4 추세 지표 3: 볼린저 밴드

### 볼린저 밴드란?

**볼린저 밴드(Bollinger Bands)**는 이동평균선을 중심으로 **표준편차**를 이용해 상단과 하단 밴드를 만들어, 가격의 상대적 위치를 파악하는 지표입니다.

### 계산 공식

```
중간 밴드(Middle Band) = 20일 SMA
상단 밴드(Upper Band) = 20일 SMA + (2 × 20일 표준편차)
하단 밴드(Lower Band) = 20일 SMA - (2 × 20일 표준편차)
```

### 실제 숫자 예시

가정: 20일 평균 = 72,000원, 20일 표준편차 = 1,500원

- 중간 밴드 = 72,000원
- 상단 밴드 = 72,000 + (2 × 1,500) = **75,000원**
- 하단 밴드 = 72,000 - (2 × 1,500) = **69,000원**

**해석**: 가격이 69,000원 ~ 75,000원 사이에서 움직일 확률이 **약 95%**

### 볼린저 밴드 활용법

**밴드의 확장과 수축**:

| 현상 | 의미 |
|------|------|
| **밴드 확장(Expansion)** | 변동성 증가 → 추세 시작 가능성 |
| **밴드 수축(Squeeze/Contraction)** | 변동성 감소 → **큰 움직임 임박** |
| 가격이 상단 밴드 터치 | 과매수 가능성 |
| 가격이 하단 밴드 터치 | 과매도 가능성 |
| 가격이 상단 돌파 | 강한 상승 추세 |
| 가격이 하단 이탈 | 강한 하락 추세 |

```
   가격
    │
    │   상단 밴드 ────╲
    │                  ╲        ← 가격이 상단 터치
    │                   ●───╲
    │                         ╲
    │   중간 밴드 ─────────────●──
    │                              ╲
    │                               ●
    │   하단 밴드 ──────────────────╲───  ← 가격이 하단 터치
    │
    └────────────────────────→ 시간
```

### 볼린저 밴드 스퀴즈(Squeeze) 전략

- **스퀴즈**: 상단과 하단 밴드가 좁아지는 현상
- **의미**: 변동성이 극도로 낮아짐 → 조만간 큰 움직임이 나올 것
- **활용**: 스퀴즈 발생 후 방향을 확인하고 진입

> 💡 **실전 활용 팁**
> 1. 볼린저 밴드는 **횡보장**에서 가장 효과적 (상단 매도, 하단 매수)
> 2. 강한 추세장에서는 가격이 계속 밴드를 따라 움직일 수 있음 (밴드 워킹)
> 3. RSI와 함께 사용하면 신뢰도가 크게 올라감

### TradingView에서 볼린저 밴드 추가하기

1. 상단 **"지표"** 버튼 클릭
2. 검색창에 **"Bollinger Bands"** 입력
3. **"Bollinger Bands"** 선택
4. 설정: Length=20, StdDev=2 (기본값 유지 추천)

## 4.5 모멘텀 지표 1: RSI (상대강도지수)

### RSI란?

**RSI(Relative Strength Index, 상대강도지수)**는 일정 기간 동안의 **상승폭과 하락폭의 비율**을 계산하여 0~100 사이의 값으로 과매수/과매도 상태를 파악하는 지표입니다.

### 계산 공식

```
RS = N일간 상승폭 평균 ÷ N일간 하락폭 평균
RSI = 100 - (100 ÷ (1 + RS))
```
- N: 기본값 14일

### 실제 숫자 예시

14일간의 가격 변동:
- 상승한 날: 8일, 총 상승폭 = 4,000원 → 평균 상승폭 = 500원
- 하락한 날: 6일, 총 하락폭 = 1,200원 → 평균 하락폭 = 200원

계산:
- RS = 500 ÷ 200 = **2.5**
- RSI = 100 - (100 ÷ (1 + 2.5)) = 100 - 28.57 = **71.43**

**결과**: RSI = 71.43 → **과매수 구간**

### RSI 해석

| RSI 값 | 상태 | 매매 판단 |
|--------|------|-----------|
| **70 이상** | 과매수(Overbought) | 매도 고려 |
| 50 ~ 70 | 상승 추세 | 매수 우위 |
| 50 | 중립 | 관망 |
| 30 ~ 50 | 하락 추세 | 매도 우위 |
| **30 이하** | 과매도(Oversold) | 매수 고려 |

```
   RSI
   100│
    90│
    80│ ← 극과매수 (매우 위험)
    70│─────────────── 과매수 경계선
    60│
    50│─────────────── 중립선
    40│
    30│─────────────── 과매도 경계선
    20│ ← 극과매도 (강한 반등 가능)
    10│
     0│
      └────────────────→ 시간
```

### RSI 다이버전스

- **상승 다이버전스**: 가격은 **신저가** + RSI는 **더 높은 저점** → 매수 신호
- **하락 다이버전스**: 가격은 **신고가** + RSI는 **더 낮은 고점** → 매도 신호

### RSI 실전 활용 시 주의점

> ⚠️ **주의: "과매수 = 즉시 매도" 아님**
> 강한 상승장에서는 RSI가 70 이상에서 몇 주 동안 유지될 수 있습니다.
> RSI 70 돌파 시 즉시 매도하지 말고, **RSI가 70 아래로 다시 내려올 때** 매도를 고려하세요.

> 💡 **실전 활용 팁**
> 1. RSI 단독 사용보다는 **추세 지표(MA, MACD)와 함께** 사용
> 2. 횡보장에서는 RSI 30/70 기준이 잘 맞음
> 3. 추세장에서는 40/80 또는 20/60으로 기준을 조정하면 더 효과적

### TradingView에서 RSI 추가하기

1. 상단 **"지표"** 버튼 클릭
2. 검색창에 **"RSI"** 또는 **"Relative Strength Index"** 입력
3. **"Relative Strength Index"** 선택
4. 설정: Length=14 (기본값)

## 4.6 모멘텀 지표 2: 스토캐스틱 (Stochastic)

### 스토캐스틱이란?

**스토캐스틱**은 일정 기간 중 **현재 가격이 상대적으로 어느 위치에 있는지**를 0~100으로 나타내는 지표입니다.

### 계산 공식

```
%K = ((오늘 종가 - N일 최저가) ÷ (N일 최고가 - N일 최저가)) × 100
%D = %K의 3일 이동평균
```
- N: 기본값 14일
- %K: 빠른 선 (Fast Line)
- %D: 느린 선 (Slow Line, 시그널)

### 실제 숫자 예시

- 14일 중 최고가: 75,000원
- 14일 중 최저가: 70,000원
- 오늘 종가: 73,500원

계산:
- %K = ((73,500 - 70,000) ÷ (75,000 - 70,000)) × 100
- %K = (3,500 ÷ 5,000) × 100 = **70**

**해석**: 오늘 가격은 14일 범위 중 **70% 위치**에 있음

### 스토캐스틱 해석

| %K 값 | 상태 | 매매 판단 |
|-------|------|-----------|
| **80 이상** | 과매수 | 매도 고려 |
| 50 ~ 80 | 상승 구간 | 매수 우위 |
| 20 ~ 50 | 하락 구간 | 매도 우위 |
| **20 이하** | 과매도 | 매수 고려 |

### %K와 %D 교차 해석

- **골든크로스**: %K가 %D를 **아래에서 위로** 돌파 → 매수 신호
- **데드크로스**: %K가 %D를 **위에서 아래로** 돌파 → 매도 신호
- 20 이하에서 골든크로스 → **강력한 매수 신호**
- 80 이상에서 데드크로스 → **강력한 매도 신호**

### RSI vs 스토캐스틱 비교

| 특성 | RSI | 스토캐스틱 |
|------|-----|------------|
| 계산 기준 | 상승/하락폭 비율 | 고가/저가 범위 내 위치 |
| 반응 속도 | 느림 | 빠름 |
| 적합한 시장 | 추세장 | 횡보장 |
| 과매수 기준 | 70 | 80 |
| 과매도 기준 | 30 | 20 |

> 💡 **실전 활용 팁**
> 1. 스토캐스틱은 **횡보장**에서 RSI보다 민감하게 반응
> 2. 추세가 강한 장에서는 오랫동안 과매수/과매도 상태에 머물 수 있음
> 3. **Slow Stochastic** (3,3 스무딩)을 쓰면 노이즈가 줄어듦

### TradingView에서 스토캐스틱 추가하기

1. 상단 **"지표"** 버튼 클릭
2. 검색창에 **"Stochastic"** 입력
3. **"Stochastic"** 선택
4. 설정: %K Length=14, %D Length=3, Smooth=3 (기본값)

## 4.7 거래량 지표 1: 거래량 분석의 중요성

### 거래량이란?

**거래량(Volume)**은 일정 기간 동안 거래된 주식(또는 코인)의 수량입니다.

**왜 거래량이 중요한가?**
- **가격은 "무엇이 일어났는가"**를 보여주고,
- **거래량은 "얼마나 강하게 일어났는가"**를 보여줍니다.

### 거래량과 가격의 관계

| 가격 | 거래량 | 해석 |
|------|--------|------|
| 상승 | 증가 | **건강한 상승** (매수세 강함) |
| 상승 | 감소 | 상승 약화, 전환 가능성 |
| 하락 | 증가 | **강한 하락** (매도세 강함) |
| 하락 | 감소 | 하락 약화, 반등 가능성 |

> 💡 **핵심 원칙**
> "거래량이 없는 가격 변동은 신뢰할 수 없다."
> 돌파(Breakout)가 발생할 때는 반드시 거래량이 동반되어야 합니다.

## 4.8 거래량 지표 2: OBV (On Balance Volume)

### OBV란?

**OBV(On Balance Volume, 누적거래량)**는 **가격이 오른 날은 거래량을 더하고, 내린 날은 거래량을 빼서** 누적하는 지표입니다.

### 계산 공식

```
오늘 종가 > 어제 종가 → OBV = 이전 OBV + 오늘 거래량
오늘 종가 < 어제 종가 → OBV = 이전 OBV - 오늘 거래량
오늘 종가 = 어제 종가 → OBV = 이전 OBV
```

### 실제 숫자 예시

| 날짜 | 종가 | 거래량 | 방향 | OBV |
|------|------|--------|------|-----|
| 1/8 | 70,000 | 100,000 | - | 0 (초기값) |
| 1/9 | 71,000 | 120,000 | 상승 | 0 + 120,000 = **120,000** |
| 1/10 | 72,000 | 150,000 | 상승 | 120,000 + 150,000 = **270,000** |
| 1/11 | 71,500 | 80,000 | 하락 | 270,000 - 80,000 = **190,000** |
| 1/12 | 73,000 | 200,000 | 상승 | 190,000 + 200,000 = **390,000** |

### OBV 해석

- **OBV 상승 + 가격 상승**: 건강한 상승 추세
- **OBV 하락 + 가격 하락**: 강한 하락 추세
- **OBV 상승 + 가격 횡보**: 매집 진행 (곧 상승 가능)
- **OBV 하락 + 가격 횡보**: 분산 진행 (곧 하락 가능)

### OBV 다이버전스

- **상승 다이버전스**: 가격은 신저가 + OBV는 더 높은 저점 → 매수 신호
- **하락 다이버전스**: 가격은 신고가 + OBV는 더 낮은 고점 → 매도 신호

> 💡 **실전 활용 팁**
> OBV의 **절대값은 중요하지 않습니다**. 오직 **방향**(상승/하락 추세)과 **다이버전스**만 봅니다.

## 4.9 거래량 지표 3: 볼륨 프로파일 (Volume Profile)

### 볼륨 프로파일이란?

**볼륨 프로파일(Volume Profile)**은 **각 가격대(Price Level)에서 얼마나 많은 거래가 이루어졌는지**를 수평 막대로 표시하는 지표입니다.

```
  가격                    가로 막대 = 거래량
   │
75,000├──█
74,000├──██                    ← POC (가장 많이 거래된 가격대)
73,000├──████████              ← 높은 거래량 집중 = 강한 지지/저항
72,000├──██████
71,000├──███
70,000├──█
   └──────────────────────→ 시간
```

### 주요 개념

- **POC (Point of Control)**: 가장 많은 거래량이 발생한 가격대
- **HVN (High Volume Node)**: 높은 거래량 구간 → 강한 지지/저항
- **LVN (Low Volume Node)**: 낮은 거래량 구간 → 가격이 빨리 통과

### 볼륨 프로파일 활용법

1. **POC를 지지/저항선으로 활용**
2. **HVN 영역 돌파 시 강한 신호로 해석**
3. **LVN 영역에서는 가격이 빠르게 움직임**

### TradingView에서 거래량 지표 추가하기

**거래량 (Volume)**:
1. 상단 **"지표"** → 검색 **"Volume"** → **"Volume"** 선택

**OBV**:
1. 상단 **"지표"** → 검색 **"OBV"** → **"On Balance Volume"** 선택

**볼륨 프로파일**:
1. 상단 **"지표"** → 검색 **"Volume Profile"** → **"Volume Profile Visible Range"** 선택 (무료)

### 4.10.2 이동평균선 계산 (SMA, EMA)

```python
"""
SMA와 EMA 계산 예제
"""
from __future__ import annotations

import pandas as pd
import pandas_ta as ta


def add_moving_averages(df: pd.DataFrame) -> pd.DataFrame:
    """
    DataFrame에 SMA와 EMA 컬럼을 추가합니다.

    Args:
        df: OHLCV DataFrame

    Returns:
        SMA와 EMA 컬럼이 추가된 DataFrame
    """
    # 단순이동평균선 (SMA)
    df["SMA_5"] = ta.sma(df["close"], length=5)
    df["SMA_20"] = ta.sma(df["close"], length=20)
    df["SMA_60"] = ta.sma(df["close"], length=60)

    # 지수이동평균선 (EMA)
    df["EMA_12"] = ta.ema(df["close"], length=12)
    df["EMA_26"] = ta.ema(df["close"], length=26)

    return df


def detect_golden_cross(df: pd.DataFrame) -> pd.Series:
    """
    골든크로스 발생 여부를 감지합니다. (5일선이 20일선을 상향 돌파)

    Args:
        df: SMA_5, SMA_20 컬럼이 있는 DataFrame

    Returns:
        골든크로스 발생 시 True, 아니면 False
    """
    prev_diff = df["SMA_5"].shift(1) - df["SMA_20"].shift(1)
    curr_diff = df["SMA_5"] - df["SMA_20"]
    return (prev_diff < 0) & (curr_diff > 0)
```

### 4.10.3 RSI 계산

```python
"""
RSI 계산 및 과매수/과매도 감지 예제
"""
from __future__ import annotations

import pandas as pd
import pandas_ta as ta


def add_rsi(df: pd.DataFrame, length: int = 14) -> pd.DataFrame:
    """
    RSI 지표를 계산하여 DataFrame에 추가합니다.

    Args:
        df: OHLCV DataFrame
        length: RSI 기간 (기본 14)

    Returns:
        RSI 컬럼이 추가된 DataFrame
    """
    df[f"RSI_{length}"] = ta.rsi(df["close"], length=length)
    return df


def rsi_signal(df: pd.DataFrame, oversold: float = 30, overbought: float = 70) -> pd.Series:
    """
    RSI 기반 매매 신호를 생성합니다.

    Args:
        df: RSI_14 컬럼이 있는 DataFrame
        oversold: 과매도 임계값
        overbought: 과매수 임계값

    Returns:
        "BUY", "SELL", "HOLD" 문자열 Series
    """
    signals: list[str] = []
    for rsi in df["RSI_14"]:
        if pd.isna(rsi):
            signals.append("HOLD")
        elif rsi < oversold:
            signals.append("BUY")
        elif rsi > overbought:
            signals.append("SELL")
        else:
            signals.append("HOLD")
    return pd.Series(signals, index=df.index)
```

## 4.11 4장 요약

- 지표는 **객관적 판단**을 돕는 도구이며, 추세/모멘텀/거래량 3가지로 분류됩니다.

- **스토캐스틱**은 일정 기간 내 현재 가격의 상대 위치를 나타냅니다.
- **OBV**는 거래량 기반 누적 지표로 추세 확인에 유용합니다.
- `pandas-ta` 라이브러리로 이 모든 지표를 Python에서 쉽게 계산할 수 있습니다.
