# tradingview-quant-bot

> TradingView Webhook + FastAPI + 업비트/KIS API를 활용한 퀀트 자동매매 시스템

## 🛠️ 기술 스택

| 분류 | 기술 |
|------|------|
| 언어 | Python 3.11+ |
| 웹 프레임워크 | FastAPI |
| 데이터 처리 | pandas, numpy |
| 기술적 분석 | pandas-ta |
| 암호화폐 거래소 | 업비트 Open API + pyupbit |
| 국내 주식 거래소 | 한국투자증권 KIS Developers |
| 스케줄링 | APScheduler |
| 데이터베이스 | SQLite (입문) / PostgreSQL (심화) |
| ORM | SQLAlchemy 2.0 |
| 환경설정 | pydantic-settings |
| 알림 | python-telegram-bot |
| 서버 | Uvicorn |

## ⚠️ 면책 조항

이 튜토리얼은 **교육 목적**으로 작성되었습니다.

- 실제 투자에 따른 손익은 **투자자 본인의 책임**이며, 이 문서의 내용은 투자 권유가 아닙니다.
- 자동매매 시스템은 반드시 **모의투자 환경**에서 충분히 테스트한 후 실전에 적용하시기 바랍니다.
- 본 튜토리얼의 작성자 및 배포자는 이 자료를 이용한 투자 결과에 대해 **어떠한 책임도 지지 않습니다**.
- 업비트 API 사용 시 **출금 권한은 절대 활성화하지 마세요**. 해킹 피해 방지.
- KIS API는 반드시 **모의투자 모드**로 시작하세요.
