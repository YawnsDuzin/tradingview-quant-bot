# 📈 TradingView Quant Bot

> **TradingView Webhook + FastAPI + 업비트/KIS API**를 활용한 퀀트 자동매매 시스템 구축 완전 가이드

주식 초보자부터 자동매매 시스템 구축까지, **단계별 완전 입문 튜토리얼**을 제공합니다.
차트 읽는 법부터 Python 백테스팅, FastAPI 서버 배포까지 한 권으로 끝냅니다.

---

## 🎯 이 튜토리얼은 누구를 위한 것인가?

- 📊 **주식 투자 경험이 전혀 없는 완전 초보자**
- 📉 차트, 지표, 매매 전략 개념을 **처음 접하는 분**
- 🐍 **Python 기초 문법**은 알고 있는 분
- 🤖 TradingView + Python + FastAPI로 **퀀트 자동매매 시스템을 만들고 싶은 분**
- 💰 암호화폐(업비트) 또는 국내 주식(KIS) 자동매매에 관심 있는 분

## 🛠️ 기술 스택

| 분류 | 기술 | 용도 |
|------|------|------|
| 언어 | **Python 3.11+** | 전체 시스템 개발 |
| 웹 프레임워크 | **FastAPI** | Webhook 수신, REST API |
| 비동기 HTTP | **httpx** | KIS API 비동기 호출 |
| 데이터 처리 | **pandas, numpy** | OHLCV 데이터 분석 |
| 기술적 분석 | **pandas-ta** | 지표 계산 (RSI, MACD 등) |
| 암호화폐 API | **pyupbit** | 업비트 매매 |
| 주식 API | **requests / httpx** | KIS Developers REST API |
| 스케줄링 | **APScheduler** | 정기 리포트, 자동 작업 |
| 데이터베이스 | **SQLite → PostgreSQL** | 주문 로그 저장 |
| ORM | **SQLAlchemy 2.0** | DB 모델링 |
| 데이터 검증 | **Pydantic v2** | Alert JSON 파싱 |
| 환경설정 | **pydantic-settings** | `.env` 관리 |
| 알림 | **Telegram Bot API** | 매매 체결/에러 알림 |
| 서버 | **Uvicorn** | ASGI 서버 |
| 컨테이너 | **Docker + Compose** | 배포 |
| 리버스 프록시 | **Nginx + Let's Encrypt** | HTTPS 처리 |
| 패키지 관리 | **uv** 또는 **pip** | 의존성 관리 |

## 🏗️ 시스템 아키텍처

```
┌─────────────────┐
│  TradingView     │   ← Pine Script로 매매 신호 발생
│  (Pine Script)   │
└────────┬────────┘
         │ HTTPS POST (JSON)
         ▼
┌────────────────────────────────────┐
│         FastAPI 서버                 │
│                                      │
│  /webhook → 검증 → 신호 파싱         │
│           → 거래소 분기              │
│           → DB 기록                  │
│           → 텔레그램 알림            │
└──┬──────────────────────┬──────────┘
   │                       │
   ▼                       ▼
┌──────────┐         ┌──────────┐
│  업비트    │         │  KIS     │
│ (코인)    │         │ (주식)   │
└──────────┘         └──────────┘
```

## ✨ 이 튜토리얼의 특징

- ✅ **완전 초보자 대상**: 중학생도 이해할 수 있는 언어로 설명
- ✅ **모든 수식에 실제 숫자 예시**: 공식만 보여주고 끝내지 않음
- ✅ **완전 실행 가능한 코드**: 복사 붙여넣기로 동작 가능
- ✅ **타입 힌트 완비**: 모든 Python 코드에 Type Hint 적용
- ✅ **비동기 방식**: FastAPI는 async/await로 작성
- ✅ **실전 중심**: 이론 설명보다 실전 팁 중심
- ✅ **단계별 체크리스트**: 무엇을 해야 할지 막막하지 않음

## ⚠️ 면책 조항 및 주의사항

### 📌 투자 면책

이 튜토리얼은 **교육 목적**으로 작성되었습니다.

- 실제 투자에 따른 **손익은 투자자 본인의 책임**이며, 이 문서의 내용은 **투자 권유가 아닙니다**.
- 자동매매 시스템은 반드시 **모의투자 환경**에서 충분히 테스트한 후 실전에 적용하시기 바랍니다.
- 본 튜토리얼의 작성자 및 배포자는 이 자료를 이용한 투자 결과에 대해 **어떠한 책임도 지지 않습니다**.

### 🔐 보안 주의사항

- 🚫 업비트 API 사용 시 **출금 권한은 절대 활성화하지 마세요**. 해킹 피해 방지.
- 🛡️ KIS API는 반드시 **모의투자 모드(`paper`)로 시작**하세요.
- 🔑 `.env` 파일은 **절대 Git에 커밋하지 마세요**. 반드시 `.gitignore`에 추가.
- 💵 첫 실전 매매는 반드시 **소액(10만원 이하)**으로 시작하세요.
